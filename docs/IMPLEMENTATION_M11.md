# M11 - 逐点轴向（倾斜 / 朝向）任务卡

状态：Canon（本阶段边界）。日期：2026-11-07。前置：M0–M10 已合入。行为真源为先行编写的 `spec/M11.md` 与 C 头文件。
触发来源：产品需求——输入需要覆盖倾斜与朝向（与同类移动便签的输入能力对齐）。
约束：每点需要坐标、压力、倾斜、朝向与时间戳五项，且时间戳非递减。

## 目标与真源

给引擎补一条**轴向通道**：宿主把笔的倾斜与朝向随样本一起写入，引擎原样保存、分段读回、并随切分 / 变换 / 复制粘贴传播。
轴向是输入元数据，不改变任何几何判定（命中、擦除、预测、规整）。

## 本轮范围

1. `SmSampleAxes { tilt, orientation }` 与 `sm_append_axes`：与坐标同批写入，值域校验，整批原子。
2. `sm_read_axes`：分段 / 容量 / `STALE_REVISION` 语义与 `sm_read_points` 一致。
3. 传播：切分插值、变换保留、规整归零、复制粘贴往返；命中与预测不读轴向。
4. 快照格式 3（`SCRATCH3`）：在格式 2 之上每样本追加 tilt / orientation；`sm_save` 只在有非默认轴向时写格式 3，`sm_load` 接受 1 / 2 / 3。
5. C ABI 新增 2 个导出与 features bit 9；C# 新增 `SampleAxes`、`AppendAxes`、`ReadAxes`；加载时核对 bit 0–9。
6. C 示例、C# 静默宿主、SDK 构建与验收脚本同步更新。
7. 便签验证器在自检里覆盖轴向往返与格式 3。

## 验收

- 追加 / 读取往返、活动笔划索引、分段读取、越界、容量不足、`STALE_REVISION`。
- 非法轴向（`tilt < 0`、`tilt > π/2`、`orientation` 越界、非有限）整批拒绝且不写入。
- 快照：无轴向 → 1；有页面标识无轴向 → 2；有轴向 → 3；载入 1 / 2 后轴向默认；格式 3 往返保持轴向、点与时间不变。
- 传播：切分插值、变换保留、规整归零、复制粘贴往返、带页面标识的格式 3 被粘贴拒绝。
- 原 M0–M10 测试断言与共享夹具不改动；唯一的例外是 M3“SCRATCH3 是未知魔数”的用例，按新规格改为 `SCRATCH9` 并补一条版本不符用例（同时改 `spec/M3.md` 的相关措辞）。
- fmt / workspace test / clippy -D warnings / release 通过；SDK 独立目录 C 动态、静态与 C# 宿主实际运行通过。
- 不声称倾斜输入在实机上可用，也不提供倾斜→笔宽的默认映射。

## 止损与边界

不做倾斜到笔锋/纹理/宽度的映射、朝向驱动的笔形、压感与倾斜联合曲线；不改命中 / 擦除 / 预测 / 规整的判定方式；不修改 PezMax-One、不建 submodule、不推送。
