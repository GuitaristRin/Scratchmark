# M8 - 形状规整任务卡

状态：Canon（本阶段边界）。日期：2026-11-07。前置：M0–M7 已合入。行为真源为先行编写的 `spec/M8.md` 与 C 头文件。
触发来源：D9 序列第三项；主流移动便签侧存在形状（直线 / 矩形 / 圆 / 箭头）与形状规整接口，Scratchmark 目前只能保留手写轨迹。

## 目标与真源

把手写笔划规整成明确几何：直线、矩形、圆、箭头。引擎只做**显式种类**的拟合与替换，不做自动分类；
宿主可以先用预览模式拿到残差，超过自己的阈值就保留手写。

## 本轮范围

1. `EnumKind`：`LINE / RECTANGLE / CIRCLE / ARROW` 四种，宿主显式指定。
2. `sm_regularize_stroke(handle, revision, index, kind, flags, out_info)`：
   - `flags` bit 0 = 只测量不替换（只读，不要求空闲、不改 revision）；
   - 否则原位替换为 1–3 笔（箭头 3 笔），一个撤销条目，轴序与索引保持；
   - 输出 `SmShapeInfo`（种类、生成笔数、生成点数、RMS 残差）。
3. 几何：轴线总体最小二乘（质心 + 协方差主方向）、轴对齐包围盒、Kåsa 圆拟合（质心平移后解 3×3）、箭头 = 轴线 + 0.18×杆长 / 28° 的两条边。
4. 生成样本：继承颜色与线宽，`flags=0`、`pressure=0`，时间在原始首末之间线性分布；点数与坐标域校验；预算超限整次失败。
5. C ABI 新增 1 个导出与 features bit 6；C# 新增 `ShapeKind`、`ShapeInfo`、`RegularizeStroke`；加载时核对 bit 0–6。
6. C 示例、C# 静默宿主、SDK 构建与验收脚本同步更新。
7. 便签验证器加入“规整”动作（按种类规整当前选区），用 `--selftest` 覆盖预览与替换。

## 验收

- 直线 / 矩形 / 圆 / 箭头各自的手算真值、残差、生成点数与退化拒绝。
- 颜色与线宽继承、元数据归零、时间线性非递减、索引与 z 序、一次撤销重做、预览零副作用、未知 kind、非法 flags、活动笔划、stale revision、索引越界、预算超限原子失败、快照往返。
- 原 M0–M7 测试断言与共享夹具不改动，全部保持通过。
- fmt / workspace test / clippy -D warnings / release 通过；SDK 独立目录 C 动态、静态与 C# 宿主实际运行通过。
- 不声称自动识别率、实机手感或规整性能已达标。

## 止损与边界

不做自动形状分类、吸附预览动画、手柄编辑、文字 / 公式识别，不改平滑与笔刷派生逻辑；不修改 PezMax-One、不建 submodule、不推送或发布。是否采纳某个残差由宿主决定，引擎不内置阈值。
