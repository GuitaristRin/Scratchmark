## M8 范围与实现

- 行为真源 `spec/M8.md`，任务卡 `docs/IMPLEMENTATION_M8.md`，裁定 D12。
- 新增 `sm_regularize_stroke(handle, revision, index, kind, flags, out_info)`：种类由宿主显式指定（直线 / 矩形 / 圆 / 箭头），引擎**不做自动分类**。
- 几何：轴线用质心 + 协方差主方向（`θ = ½·atan2(2Sxy, Sxx−Syy)`）；矩形取轴对齐包围盒、5 点闭合；圆用 Kåsa 拟合（质心平移后解 3×3 正规方程）、65 点闭合；箭头 = 轴线 + 0.18×杆长 / 28° 两条边，共 3 笔。
- `flags` bit 0 是**预览**：只返回残差 `error`，不写文档、不占历史、不要求空闲，宿主据此决定是否采纳；实际替换一次只占一个撤销条目，颜色与线宽继承、样本压力归零、时间在原始首末之间线性分布。
- 替换复用 M5 的“按下标替换”条目（一笔变多笔），生成笔划占据原索引，后续笔划顺延；预算按“含历史在内”校验，超限整次失败。
- C ABI 新增 1 个导出与 features bit 6；SDK 0.8.0 / ABI 1，快照格式 1 / 2 不变。C# 新增 `ShapeKind`、`ShapeInfo`、`RegularizeStroke`，加载时核对 bit 0–6。

## M9 视口旋转与视口辅助（同日开工并验收）

- 行为真源 `spec/M9.md`，任务卡 `docs/IMPLEMENTATION_M9.md`，裁定 D13；旧 `SmViewport` 与五个旧导出**逐位不变**。
- 新增 `SmViewportEx { scale, angle, offset_x, offset_y, reserved }`：`v = scale·R(θ)·p + offset`，逆变换 `R(−θ)·((v − offset)/scale)`；线宽只随 `scale`；`bounds` 返回旋转后的轴对齐外接框。
- 两个宿主真会用到的辅助：`sm_viewport_ex_zoom_at`（锚点下的页面点不动，`offset' = anchor − (anchor − offset)·factor`）与 `sm_viewport_ex_fit`（按旋转外接框等比缩放并居中，带内边距）。
- C ABI 新增 7 个导出与 features bit 7；SDK 0.9.0 / ABI 1，快照格式 1 / 2 不变。C# 新增 `ViewportEx`（含 `ZoomAt` / `Fit`），加载时核对 bit 0–7。
- 新增核心 7 项视口旋转测试与 FFI 4 项；既有 M0–M8 断言与共享夹具不改动。
- fmt、133 项 workspace 测试、clippy `-D warnings`、release 通过。
- Windows SDK 源码树外解压验证：C 动态 381、C 静态 381、C# 409 项通过；托管 0 警告 0 错误；校验和与快照一致。包：`dist/scratchmark-0.9.0-x86_64-pc-windows-gnu-bac09033.zip`。
