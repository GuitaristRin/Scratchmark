# M2 - 在线平滑与压力笔刷任务卡

状态：Canon（本阶段边界）。日期：2026-11-04。用户在阶段选择中明确“先做平滑与压力笔刷”。

## 目标与真值

在现有书写、读取、保存恢复基础上，由引擎生成在线平滑轨迹与逐点压力笔宽。原始样本保持不变，宿主负责实际像素呈现。

行为以先行编写的 `spec/M2.md` 和 C 头文件为真源。现有 M0 快照格式 1 保持可读、可写；不将此实验扩展宣称为稳定发布接口。

## 本轮范围

1. 提供可配置、因果的坐标低通平滑；第一点不偏移，输入批次切分不影响结果，不等待凑批、不生成预测点。参数与采样率有关，实验中明示滞后，不声称设备手感已达标。
2. 按可用压力映射逐点线宽，无压力时保持原固定线宽；允许关闭压力映射或关闭平滑，支持鼠标等无压输入。
3. 原始样本与格式 1 快照不变，平滑 / 压力是按读取参数生成的派生几何。宿主需保留读取配置，才能重现相同外观；每笔专属笔刷配置持久化不在本轮冒充已完成。
4. 活动笔划可增量读取派生轨迹，原 revision 规则不变；缓存按每笔一组配置有界保存，切换配置时重算，不反复为每次分段读取扫描整笔。
5. 从 Rust 核心贯通 C ABI、C# 与独立 SDK 宿主；原导出签名和 ABI 1 保持，新增能力位与加载检查区分新旧库。

## 验收

- 用手算序列核对平滑坐标和压力笔宽，覆盖单点、重复点、无压力、混合能力、关闭配置、异常参数与任意批次 / 读取切分。
- 验证原始数据不变、失败原子性、缓存无可见状态变更、撤销重做与保存恢复后派生结果一致。
- 原共享格式夹具不改动；读取旧快照、输出格式 1 并逐字节核对。
- fmt / workspace test / clippy / release 构建通过；SDK 独立目录 C 动态、静态与 C# 宿主实际运行。
- 用实际 DLL 输出绘制离线对照图并亲自查看，报告可复现的轨迹 / 笔宽数字；此图不是实机手感验收。
