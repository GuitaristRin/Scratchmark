# M5 - 沿擦除路径的局部擦除任务卡

状态：Canon（本阶段边界）。日期：2026-11-05。前置：M0–M4 已合入。行为真源为先行编写的 `spec/M5.md` 与 C 头文件。

## 目标与真源

在 M4 的命中与整笔擦除之上补齐橡皮擦的第二种形态：沿一条擦除路径切分笔划，只去掉路径覆盖的部分。贯通统一编辑历史、快照、C ABI 与 C#，并保持 M0–M4 的既有断言与共享夹具不变。

## 本轮范围

1. 核心：`erase_path(revision, path, radius)` 按原始中心线计算覆盖区间，把笔划切成片段；片段继承宽度 / 颜色并与原索引同位。
2. 编辑历史：新增“按下标替换”条目，一次手势只产生一个撤销条目；撤销恢复原索引与 z 序，重做再次切分。
3. 预算：片段点数计入“含历史在内”的上限；超限返回 `LIMIT_EXCEEDED` 且不改动文档。
4. C ABI 新增 1 个导出与 features bit 3；既有导出签名与语义不变。
5. C# 适配层新增 `ErasePath`；加载库时核对 bit 0–3。
6. C 示例、C# 静默宿主、SDK 构建与验收脚本同步更新。
7. 核心、FFI、C、C# 测试覆盖规格中的边界与原子性。

## 验收

- 垂直切分与切点坐标（时间与压力插值）、拐角与单点笔划、顶点被覆盖、整笔删除、相切不切分、未受影响笔划不变、跨多笔划的单一撤销条目、撤销恢复原索引与 z 序、重做再切分、成功清除重做、失败原子性、预算超限、快照往返与 load 后可撤销。
- 原 M0 / M2 / M3 / M4 测试断言与共享夹具不改动，全部保持通过。
- fmt / workspace test / clippy -D warnings / release 通过；SDK 独立目录 C 动态、静态与 C# 宿主实际运行通过。
- 不声称实机擦除手感、擦除性能或触控目标尺寸已达标。

## 止损与边界

不实现套索、形状工具、选区移动、预测笔迹、多页管理、Android、MSVC / UWP；不修改 PezMax-One、不建 submodule、不推送或发布。擦除半径与路径由宿主按视口换算后传入，引擎不内置 UI 目标尺寸。
