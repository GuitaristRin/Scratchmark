# 当前工程状态

状态：Draft，交接快照。日期：2026-11-03。实施范围参 [M0 任务卡](IMPLEMENTATION_M0.md)，行为参 [M0 规格](../spec/M0.md)。

## 已完成的 M0 路径

- `scratchmark-core`：固定宽度折线、批量采样、活动笔迹读取、保守边界、提交 / 取消、整笔撤销重做、可编辑快照导出 / 导入。
- `scratchmark-ffi`：14 个 C ABI 导出，数值句柄、每文档互斥、容量 / 对齐 / 空值检查、revision 读取校验、unwind 截获。
- 独立 C 宿主通过运行时动态加载调用全部导出；实际写入快照、销毁引擎、读盘后加载到新引擎并继续编辑。
- `tools/build-sdk.ps1` 与 `tools/verify-sdk.ps1`：构建、SHA-256、版本身份、ZIP 打包和独立宿主验收。当前只验收 Windows x64 GNU 目标。
- 不依赖既有基线代码 / 资产，不引入第三方 crate，不修改其他仓库，不建立 submodule。

本节由 S1 任务卡在 Fedora 44 借用机上追加，只补 Linux x86_64 构建与独立 C 宿主验收；上方 Windows 结论原样保留，不作改动。核心 / FFI 代码与 ABI 未变更，工作范围仅 `tools/**` 与本文件。

本轮最终包为 `dist/scratchmark-0.1.0-x86_64-unknown-linux-gnu-1dd14ea3.tar`，54,507,520 字节，SHA-256 为 `65a4a203e89c39e4d6c4b65871c853c301031b79d38ab64be059c94069501f75`。源码基线为 `5885a201c46a6f04086f45121ffb9a0dbd6ce4a4`，包内 `build-info.json` 记录 `sourceDirty: false`；解包验证输出在 Git 忽略的 `artifacts/sdk-verify-0ee0b79f/`。打包脚本为 `tools/build-sdk.sh`，验收脚本为 `tools/verify-sdk.sh`，包结构对齐 Windows 版（`bin/` 动态库、`include/`、`examples/`、`spec/`、`build-info.json`、`SHA256SUMS`），以 tar 代替 ZIP，并新增 `lib/` 存放静态库。

与 Windows 结论的差异：14 项 Rust 测试与 54 项独立宿主检查结果一致，包语义一致；本轮缺少 rustfmt / clippy 证据（Windows 轮两者通过），这两条门禁在 Linux 上仍未验证；Windows 轮检查了 DLL 导入表未列额外运行库 DLL，本轮以 `nm -D` 与 `ldd` 做了等价的只读核对；本包额外包含静态库 `libscratchmark.a`，但静态链接接入路径未验收，包内仅动态加载示例。

仍然未验证：Android、Windows MSVC、UWP / .NET Native 与 C# 绑定；Linux 静态库链接；性能基准与设备手感。这些结论不因本轮而改变。
