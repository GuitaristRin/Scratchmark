# 当前工程状态

状态：Draft，交接快照。日期：2026-11-03。实施范围参 [M0 任务卡](IMPLEMENTATION_M0.md)，行为参 [M0 规格](../spec/M0.md)。

## 已完成的 M0 路径

- `scratchmark-core`：固定宽度折线、批量采样、活动笔迹读取、保守边界、提交 / 取消、整笔撤销重做、可编辑快照导出 / 导入。
- `scratchmark-ffi`：14 个 C ABI 导出，数值句柄、每文档互斥、容量 / 对齐 / 空值检查、revision 读取校验、unwind 截获。
- 独立 C 宿主通过运行时动态加载调用全部导出；实际写入快照、销毁引擎、读盘后加载到新引擎并继续编辑。
- `tools/build-sdk.ps1` 与 `tools/verify-sdk.ps1`：构建、SHA-256、版本身份、ZIP 打包和独立宿主验收。当前只验收 Windows x64 GNU 目标。
- 不依赖既有基线代码 / 资产，不引入第三方 crate，不修改其他仓库，不建立 submodule。

| `cargo clippy --workspace --all-targets -- -D warnings` | 通过，无告警。 |
| `cargo build --release --workspace` | 通过；生成 DLL、GNU 静态库和 Rust 库产物。 |

测试覆盖黄金字节、截断 / 损坏 / 超限快照、无效样本批次原子性、活动状态限制、重做分支、stale revision、内存容量和句柄错误、多线程同句柄调用、panic 隔离边界。黄金夹具只在 `spec/fixtures/simple-v1.hex` 维护。

本地验收产物在 Git 忽略的 `artifacts/` 与 `dist/`，包括实际快照、解包验证目录及 SDK ZIP。包内 `build-info.json` 记录对应源码与 dirty 状态，不把开发工作区产物当成已发布稳定版本。

本轮最终包为 `dist/scratchmark-0.1.0-x86_64-pc-windows-gnu-7997ff28.zip`，828,203 字节，SHA-256 为 `deaa64b639191b9ace5495ceb5eb94f07cfc3e736f8eb8b94e507603ae3a004e`。源码基线为 `e51a82d6d18e7d73ba5c33eb96c3a015c26b212d`；解包验证输出保存在 `artifacts/sdk-final-5bfe24b5/verification.txt`。包内 dirty 标记为 true，打包时工作区另有非本轮写入的未跟踪任务卡；引擎与 SDK 构建源码已纳入该基线提交。

## 未实现 / 未验证

- Android SDK / NDK 未在已检查的默认路径和对应环境变量中找到，当前 Rust 仅安装 Windows GNU target；没有生成或运行 Android SO / JNI / AAR。
- Linux SO、Windows MSVC、UWP / .NET Native 与 C# 绑定未构建 / 未运行。Windows C 加载证据不能外推到这些路径。
- 窗口、参考前端、像素渲染、压力笔刷、平滑、预测、防误触、擦除、套索、形状工具未实现；没有出界面图。
- 页面业务标识、坐标变换协议、稳定外部契约与长期存储迁移仍未确定。M0 仅保留页面局部坐标，不支持页面换版自动重定位。
- 未运行性能基准或实机体验测试，不报告延迟、功耗、手感与跨语言损耗比例。快照写盘成功不代表宿主文件事务已获得崩溃恢复保证。
- SDK 当前为本地实验验收包，尚未确定公开发布与授权策略，未上传或推送。
