# M14 - 按笔宽的点间距重采样任务卡

状态：Canon（本阶段边界）。日期：2026-11-07。前置：M0–M13 已合入。行为真源为先行编写的 `spec/M14.md` 与 C 头文件。
触发来源：清单新增缺口 A4（`docs/research/2026-11-07-oppo-capability-inventory.md` 第六、八节），
证据为 `原生库` 各笔型类的 `间距查询(float)` 与 `插值(int, Point*)`。

## 目标与真源

宿主铺笔触需要“按固定步距取点”，而 Scratchmark 只有逐样本派生（M2）。本轮补一个只读重采样：
`间距 = 笔宽 × 比例`，沿中心线按弧长等距取点，末尾保留原始末点，并把逐点笔宽一并给出。

## 本轮范围

1. `SmResampleOptions { spacing_ratio, brush, reserved }` 与 `sm_resample_stroke`。
2. 取点规则：首点 = 原始首点、按弧长等距、末点 = 原始末点；单点 / 退化笔划返回 1 点；拐角跨段不重复。
3. 逐点笔宽取 M2 派生值并在相邻派生点间线性插值。
4. 容量语义：不足时回报所需数量（不写数组），查询模式可用；点数超 `MAX_POINTS` 返回 `LIMIT_EXCEEDED`。
5. C ABI 新增 1 个导出与 features bit 12；C# 新增 `ResampleOptions` 与 `Resample`；加载时核对 bit 0–12。
6. C 示例、C# 静默宿主、SDK 构建与验收脚本同步更新。
7. 便签验证器加一个“按间距重采样当前选区”的自检覆盖。

## 验收

- 直线的点数与坐标手算一致（比例取 1 / 0.6 / 2.5）；笔宽加倍使点距加倍、点数约减半。
- 拐角跨段连续且顶点不重复；单点与退化笔划返回 1 点；压力笔划的宽度与 M2 派生一致。
- 非法比例 / 笔刷 / reserved、`STALE_REVISION`、容量不足、查询模式、点数超限。
- 原 M0–M13 断言与共享夹具不改动，全部保持通过。
- fmt / workspace test / clippy -D warnings / release 通过；SDK 独立目录 C 动态、静态与 C# 宿主实际运行通过。
- 不声称重采样的实机观感；纹理与虚线仍归宿主。

## 止损与边界

不做纹理铺贴、虚线、按笔型的密度差异；重采样只读、不进快照；不修改 PezMax-One、不建 submodule、不推送。
