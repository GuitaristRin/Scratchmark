# 0.1.0-pre 发布说明

**实验版**。接口（C ABI 1）与快照格式（1/2/3）都不承诺兼容，后续版本可能直接改动。

## 这是什么

无 UI 的手写笔迹引擎：宿主把采样点交给它，它负责几何、编辑历史、命中与擦除、形状规整、预测、快照，
渲染、视口、文件 I/O、剪贴板系统集成都由宿主承担。核心用 Rust 写，对外三种调用方式：C ABI、JNI（Android）、
以及在此基础上手写的 .NET 与 Kotlin 封装。

## 能力（52 个 C 导出，能力位 bit 0–16）

采样与派生：批量输入、在线平滑、逐点压力笔宽、逐点倾斜/朝向、点间距重采样、笔型尺寸预置。
编辑：整笔擦除、沿路径局部擦除（切口带标记）、按索引批量删除、清空、选区仿射变换、复制/粘贴、原子剪切、整份平移。
查询：命中测试、套索命中、逐笔信息、文档边界、预测尾迹（含刷新率窗）。
持久化：自描述快照（格式 1 / 2 / 3，按内容自动选择）。

## 许可

MIT 或 Apache-2.0，任选其一。第三方组件见 `NOTICE`（当前唯一第三方依赖是 `jni`，同样为 MIT/Apache-2.0）。

## 已知限制

- 引擎不出位图，也不读时钟、不起线程；`time_us` 由宿主给。
- 每份文档一把锁；不同文档可并发，同一文档请串行调用。
- 快照上限 64 MiB，坐标上限 1e9，单文档 100 万点 / 10 万笔。

## 反馈

实验期接口会变，请把"你依赖了哪个导出 + 期望行为"写清楚，便于判断是缺陷还是契约调整。
