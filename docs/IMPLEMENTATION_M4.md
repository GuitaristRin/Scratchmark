# M4 - 命中测试与整笔擦除任务卡

状态：Canon（本阶段边界）。日期：2026-11-05。前置：M0–M3 已合入。

## 目标与真源

在现有书写、派生笔刷、页面标识与视口之上，补齐编辑器最基础的命中测试与整笔擦除，并贯通撤销 / 重做、快照、C ABI 与 C#。行为真源为先行编写的 `spec/M4.md` 与 C 头文件。

## 本轮范围

1. `sm_hit_test`：对已提交笔划做原始中心线命中测试；活动笔划不参与；多命中取最上层；容差为页面单位。
2. `sm_erase_stroke`：空闲时按索引删除整笔；revision 绑定；成功清除重做并进入撤销历史。
3. 统一编辑历史：新增与删除共用撤销 / 重做顺序，删除撤销后恢复原 z 序；资源预算含历史。
4. C ABI 新增 2 个导出与 features bit 2；既有导出签名与语义不变。
5. C# 适配层新增命中 / 擦除方法；加载库时核对 bit 0–2。
6. C 示例、C# 静默宿主、SDK 构建与验收脚本同步更新。
7. 核心、FFI、C、C# 测试覆盖规格中的边界与原子性。

## 验收

- 命中：线段、端点、拐角、单点、容差 / 宽度边界、上层优先、活动笔划排除、空文档、stale revision、非法输入、错误不写输出。
- 擦除：索引边界、活动笔划拒绝、stale revision、撤销恢复原 z 序、重做再删除、finish 清空重做、cancel 保留历史、快照只含存活笔划、load 后重做清空且载入笔划可整笔撤销。
- 原 M0 / M2 / M3 测试断言与共享夹具不改动，全部保持通过。
- fmt / workspace test / clippy -D warnings / release 通过；SDK 独立目录 C 动态、静态与 C# 宿主实际运行通过。
- 不声称实机手感、命中性能或触控目标尺寸已达标。

## 止损与边界

不实现局部擦除、套索、选择、预测、形状工具、多页管理、Android、MSVC / UWP；不修改 PezMax-One、不建 submodule、不推送或发布。命中容差由宿主按视口换算后传入，引擎不内置 UI 目标尺寸。
