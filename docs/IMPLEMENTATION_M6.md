# M6 - 套索命中、批量删除与清空任务卡

状态：Canon（本阶段边界）。日期：2026-11-06。前置：M0–M5 已合入。行为真源为先行编写的 `spec/M6.md` 与 C 头文件。
触发来源：便签验证器 `Projects/Scratchmark-Verifier` 的能力对照暴露出两个缺口——套索 / 批量删除未实现，清空没有专用 API（只能逐笔删除，撤销粒度等于笔划数）。

## 目标与真源

补齐“先框选、再一次性处理”的编辑路径，并给清空一个原子操作。引擎只做只读命中查询与按索引的原子删除，不保存选区状态。

## 本轮范围

1. `sm_lasso_hits`：闭合多边形（even-odd 内部判定）对已提交笔划原始中心线的命中查询，输出升序索引；容量不足按 M0 的 `BUFFER_TOO_SMALL` 语义回报所需数量。
2. `sm_erase_indices`：空闲时按索引批量删除，去重规则明确（重复即拒绝），一次调用一个撤销条目，撤销按原索引恢复 z 序。
3. `sm_clear`：空闲时一次清空全部已提交笔划，同样只占一个撤销条目。
4. C ABI 新增 3 个导出与 features bit 4；既有导出签名与语义不变。
5. C# 适配层新增 `LassoHits` / `EraseIndices` / `Clear`；加载库时核对 bit 0–4。
6. C 示例、C# 静默宿主、SDK 构建与验收脚本同步更新。
7. 核心、FFI、C、C# 测试覆盖规格中的边界与原子性。
8. 便签验证器加入套索工具与“清空”按钮，实际跑通“框选 → 删除 → 撤销”。

## 验收

- 套索：三顶点最小多边形、内含 / 相交 / 仅接触边界 / 在外、单点笔划、凹多边形、自交、重复顶点、活动笔划排除、容量不足与查询模式、非法路径与 `count < 3`、stale revision、不写输出。
- 删除：越界、重复索引、空列表、活动笔划、stale revision、撤销恢复原 z 序、重做再删、`clear` 单条撤销、`clear` 空文档不改 revision、快照往返与 load 后重做清空。
- 原 M0 / M2 / M3 / M4 / M5 测试断言与共享夹具不改动，全部保持通过。
- fmt / workspace test / clippy -D warnings / release 通过；SDK 独立目录 C 动态、静态与 C# 宿主实际运行通过。
- 不声称实机套索手感、选择性能或触控目标尺寸已达标。

## 止损与边界

不实现选区变换（移动 / 缩放 / 旋转）、形状规整、预测笔迹、多页管理、Android、MSVC / UWP；不修改 PezMax-One、不建 submodule、不推送或发布。引擎不定义套索手势的输入策略（输入源、防误触、闭合方式）与选区高亮样式，这些由宿主决定。
