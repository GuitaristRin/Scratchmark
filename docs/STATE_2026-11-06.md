## M6 范围与实现

- 行为真源 `spec/M6.md`，任务卡 `docs/IMPLEMENTATION_M6.md`，裁定 D9 / D10。
- 核心新增 `lasso_hits`：闭合多边形按 even-odd 判定内部，笔划原始中心线与区域相交或内含即命中，输出升序索引；查询只读，不要求空闲、不改 revision。
- 核心新增 `erase_indices` 与 `clear`：空闲时按索引或整份删除，重复索引直接拒绝，一次调用只产生**一个**撤销条目，撤销按原索引逆序插回、z 序完全恢复。
- 复用 M5 的“按下标替换”历史条目（删除即 `after` 为空的替换），没有另开一套历史。
- C ABI 新增 `sm_lasso_hits`（容量不足按 M0 的 `BUFFER_TOO_SMALL` 语义回报所需数量）、`sm_erase_indices`、`sm_clear` 与 features bit 4；SDK 0.6.0 / ABI 1，快照格式 1 / 2 不变。
- C# 新增 `LassoHits`（先查询所需数量再取数组）、`EraseIndices`、`Clear`，加载时核对 bit 0–4。
