# M12 - 文档边界、整份平移与页面尺寸归属任务卡

状态：Canon（本阶段边界）。日期：2026-11-07。前置：M0–M11 已合入。行为真源为先行编写的 `spec/M12.md` 与 C 头文件。
触发来源：`docs/research/2026-11-07-oppo-capability-inventory.md` 的缺口 F1 / F2（画布扩展与内容偏移）。

## 目标与真源

参考实现 的画布能边写边增长（`外部实现.extendCanvas` / `rolling` / `topBlank`）。读下来，其中**页面高度、顶部留白、
内容偏移与滚动**都是显示布局，**真正缺的引擎能力只有两件**：告诉宿主“内容占到哪儿”，以及“整份内容能不能一次平移”。
本轮补这两件，并把页面尺寸明确划归宿主，避免为此再动快照格式。

## 本轮范围

1. `sm_document_bounds`：已提交笔划的并集边界 + 笔划数，含笔宽；空文档 `found=0`；只读。
2. `sm_translate_all`：整份平移，一次调用一个撤销条目；越界整次失败；空文档空操作。
3. 页面尺寸归属写进 `spec/M12.md` 与 `HOST_INTEGRATION.md`：引擎不入快照、宿主自行保留。
4. C ABI 新增 2 个导出与 features bit 10；C# 新增 `DocumentBounds`、`TranslateAll`；加载时核对 bit 0–10。
5. C 示例、C# 静默宿主、SDK 构建与验收脚本同步更新。
6. 便签验证器加“整份下移”动作，用于模拟“从顶部加长画布”。

## 验收

- 边界：空文档、单笔、多笔并集、活动笔划排除、过期 revision、输出指针无效不写入。
- 平移：正负方向、一次撤销、越界原子失败、活动笔划拒绝、空文档空操作、线宽与轴向不变、快照往返。
- 原 M0–M11 测试断言与共享夹具不改动，全部保持通过。
- fmt / workspace test / clippy -D warnings / release 通过；SDK 独立目录 C 动态、静态与 C# 宿主实际运行通过。
- 不实现页面尺寸持久化、滚动惯性、顶部留白策略；不声称实机手感。

## 止损与边界

不改快照格式（仍是 1 / 2 / 3）；不做无限画布、多页、缩略图；不修改 PezMax-One、不建 submodule、不推送。
