# M16 - 原子剪切任务卡

状态：Canon（本阶段边界）。日期：2026-11-07。前置：M0–M15 已合入。行为真源为先行编写的 `spec/M16.md` 与 C 头文件。
触发来源：清单 E1 行的“部分”标记——同类产品的选区剪切是单个原语，
而 Scratchmark 要宿主复制 + 删除两步，撤销一次只回退一半。

## 目标与真源

把“复制选区 + 删除选区”合成一次调用：先编码剪贴板字节（与 `sm_copy_strokes` 一致），再在同一个撤销条目里移除选区。

## 本轮范围

1. 核心 `Document::cut_strokes`：编码 → 一次编辑删除（复用 M6 的按下标移除与 M7 的编码）。
2. `sm_cut_strokes`：容量语义与 `sm_save` / `sm_copy_strokes` 一致；**查询模式不剪切**。
3. C ABI 新增 1 个导出与 features bit 14；C# 新增 `CutStrokes`；加载时核对 bit 0–14。
4. C 示例、C# 静默宿主、SDK 构建与验收脚本同步更新。
5. 便签验证器把“剪切”按钮从两步组合改为单次调用，并在自检里覆盖“一次撤销整体恢复”。

## 验收

- 单笔 / 多笔（乱序）剪切、剪贴板可粘贴回原几何、一次撤销整体恢复。
- 带轴向的笔划剪切后剪贴板为格式 3 且页面标识为 0。
- 空列表 / 重复 / 越界 / 过期 revision / 活动笔划 / 容量不足 / 查询模式：文档都不变。
- 原 M0–M15 断言与共享夹具不改动，全部保持通过。
- fmt / workspace test / clippy -D warnings / release 通过；SDK 独立目录 C 动态、静态与 C# 宿主实际运行通过。

## 止损与边界

不做系统剪贴板、跨文档剪切、剪切后自动重排；不改快照格式；不修改 PezMax-One、不建 submodule、不推送。
