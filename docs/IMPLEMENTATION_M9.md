# M9 - 视口旋转与视口辅助任务卡

状态：Canon（本阶段边界）。日期：2026-11-07。前置：M0–M8 已合入。行为真源为先行编写的 `spec/M9.md` 与 C 头文件。
触发来源：D9 序列第四项；M3 的视口只有缩放 + 平移，`spec/M3.md` 明确把旋转留给宿主，但宿主没有可用的纯函数，页面内容与笔迹在旋转下无法自证对齐。

## 目标与真源

给视口补上旋转，并把宿主真正需要的两个辅助一起做成纯函数：以视口点为锚缩放、把页面边界适配进视口矩形。
旧 `SmViewport` 与五个旧导出保持逐位不变，新能力走新结构，旧宿主不受影响。

## 本轮范围

1. `SmViewportEx { scale, angle, offset_x, offset_y, reserved }`：先缩放、再旋转、最后平移；逆变换为 `R(−θ)·((v − offset)/scale)`。
2. 五个扩展导出：页面 ↔ 视口、线宽（只随 `scale`）、旋转后轴对齐外接框。
3. `sm_viewport_ex_zoom_at`：`offset' = anchor − (anchor − offset)·factor`，锚点下的页面点不动。
4. `sm_viewport_ex_fit`：按旋转后外接框等比缩放并居中，带内边距。
5. C ABI 新增 7 个导出与 features bit 7；`SmViewport` 与旧导出不改。
6. C# 新增 `ViewportEx` 与对应方法；加载时核对 bit 0–7。
7. C 示例、C# 静默宿主、SDK 构建与验收脚本同步更新。
8. 便签验证器改用 `ViewportEx`：滚轮以光标为锚缩放、Ctrl+[ / Ctrl+] 旋转、适应窗口走引擎的 fit。

## 验收

- 角度 0 / 90 / 180 / 45 / 负角 / 大于 2π：手算真值、往返 ≤ 1e-9、90° 时外接框宽高互换、45° 放大 √2。
- 非法输入（`scale ≤ 0`、非有限、`reserved ≠ 0`、页面域越界、`factor ≤ 0`、`padding` 越界、视口尺寸 ≤ 0、`bounds` 反序）全部不写输出。
- `zoom_at` 锚点不动；两次缩放等价于合成缩放。
- `fit` 在 0° 与 90° 下居中且内边距生效；退化页面与过大内边距被拒绝。
- 原 M0–M8 测试断言与共享夹具不改动，全部保持通过。
- fmt / workspace test / clippy -D warnings / release 通过；SDK 独立目录 C 动态、静态与 C# 宿主实际运行通过。
- 不声称实机旋转显示效果、手势或惯性已验收。

## 止损与边界

不做旋转手势、惯性、吸附、非等比视口缩放、整页旋转换算策略；不修改 PezMax-One、不建 submodule、不推送或发布。旋转中心与角度由宿主决定，引擎只提供纯函数换算。
