# M0 - 独立引擎与 C ABI 基础闭环

状态：Canon。授权：2026-11-03 用户同意二进制分发方向并要求开始工程实施。本卡限定首个工程阶段，不替代后续体验验证任务。

## 目标与真值

提供无 UI、无第三方依赖的 Rust 核心，通过实验性 C ABI 在独立 C 宿主中加载动态库，完成批量输入、活动笔迹读取、提交 / 取消、撤销重做、导出 / 导入后继续编辑。

行为真源为 [M0 规格](../spec/M0.md)，函数与类型声明为 [C 头文件](../include/scratchmark.h)。先写规格，再实现；本阶段不发布稳定接口承诺。

## 范围

- 单文档、单活动笔划、页面局部坐标、固定宽度折线；保留时间与可用压力样本，但不实现压力笔刷、平滑或预测。
- 读取笔划元数据、边界与分段采样；版本号防止宿主混用不同状态的数据。
- 内存内导出与导入可编辑快照，宿主负责文件事务；未提交笔划不自动保存。
- Rust `cdylib` / `staticlib` 构建；Windows 独立动态加载示例与 SDK 打包脚本。
- 源码保持平台无关；Android / Linux 构建与运行证据分别列出，不由 Windows 结果外推。

## 验收

1. `cargo fmt --all -- --check`、`cargo test --workspace`、`cargo clippy --workspace --all-targets -- -D warnings` 零错误。
2. `cargo build --release --workspace` 成功；独立 C 宿主编译并通过动态加载、生命周期、取消、快照恢复和错误路径验收。
3. SDK 复制到没有源码的独立目录后仍可加载；压缩包可由 `tar -tf` 列出，包含头文件、动态库、示例、规格、构建身份和校验清单。
4. 非有限坐标、逆序时间、无效压力、损坏 / 过量快照、失效句柄及容量不足有明确结果；失败不得部分改变笔迹。
5. 不连接真实设备，不出界面图，不报告手感或端到端性能达标。

## 止损

不修改其他仓库，不使用既有基线代码或资产，不新增依赖，不上传或推送产物。缺失的目标工具链记录为未验证，不安装大型工具链绕过范围。正式渲染输出、页面业务身份、平台绑定与跨端格式兼容另开阶段。
