# M3 - 页面标识与视口变换任务卡

状态：Canon（本阶段边界）。日期：2026-11-04。前置：Linux 门已补齐（fmt / test / clippy / release / SDK 动态与静态独立验收），见 STATE 2026-11-04。

## 目标与真值

在 SDK 0.2.0 的书写、派生笔刷、保存恢复之上，补齐页面维度的两个缺口：稳定页面标识，以及页面坐标 ↔ 视口坐标的引擎侧原语。原始样本、既有接口语义与 M0/M2 行为不变；行为真源为先行的 [M3 规格](../spec/M3.md) 与 C 头文件。

## 本轮范围

1. 页面标识 u64（0 = 未设置）：get / set、空闲限制、revision 规则、撤销 / 重做不回退。
2. `SmViewport`（uniform scale + offset）纯函数：page ↔ viewport 点、线宽 / 命中容差、边界；页面域与有限性校验，失败不写输出。
3. 快照格式 2（独立魔数 `SCRATCH2` + u64 页面标识）：设置了页面引用写格式 2，未设置仍写格式 1；load 兼容两者；跨页标识冲突拒绝且原子。格式 1 魔数与语义逐字节不变，既有夹具与断言全部保持。
4. C ABI 新增 7 个导出与 features bit 1；`SmState` 与原导出语义不变。
5. C# 适配层：Viewport / Point / Bounds 类型、页面标识读写、变换方法；加载库时核对 bit 1。本机无 .NET 9，本轮只交付代码，不做托管运行验收。
6. 离线预览：用真实 `.so` 输出生成缩放 / 平移前后对照 PNG；PNG 用本机已有 Pillow（12.3.0，本轮未安装任何组件）写出并标注坐标数值。

## 验收

- 手算真值核对正 / 逆变换与线宽缩放；identity 视口逐位相等；roundtrip 相对误差有界。
- 同一 SmViewport 下，输入路径（视口→页面→append→读取）与显示路径（读取→页面→视口）几何一致；命中容差换算一致。
- 非法 / 极值输入：NULL、不对齐、非有限、页面域越界、溢出、下溢、reserved 非零；错误不写输出、不改 revision 与缓存。
- 页面标识：空页面、活动笔划期间拒绝、相同值不递增 revision、跨页 load 拒绝、撤销 / 重做保持、重开恢复一致。
- 原测试不改断言全绿；fmt / clippy -D warnings / release / SDK 独立验收（动态 + 静态 + `nm -D` 导出清单 + `ldd` 无引擎依赖 + 快照一致）在本机复跑。
- 预览图亲自查看并标注坐标数值；它是离线参考图，不是实机手感或显示性能结论。

## 止损与边界

不修改 PezMax-One、不建 submodule、不推送 / 发布。旋转、非线性变形、命中 / 擦除 API、多页管理、Android、MSVC / UWP、每笔视口历史另行推进。本机缺 .NET 9 时 C# 不做运行验收，如实记录为未验证项。
