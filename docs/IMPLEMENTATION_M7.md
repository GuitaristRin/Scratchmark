# M7 - 选区变换与复制粘贴任务卡

状态：Canon（本阶段边界）。日期：2026-11-06。前置：M0–M6 已合入。行为真源为先行编写的 `spec/M7.md` 与 C 头文件。
触发来源：D9 序列第二项；M6 之后“框选”已经可用，但框选完不能移动 / 缩放，也没有复制粘贴。

## 目标与真源

给选区一个可用的编辑闭环：原位变换（平移 / 缩放 / 旋转 / 镜像 / 剪切）、复制成字节、粘贴回文档。
剪贴板内容就是格式 1 快照字节，宿主可以自己保存或跨页使用；引擎不做系统剪贴板集成。

## 本轮范围

1. `SmTransform`：6 系数仿射矩阵，校验有限性与行列式范围，`NULL` 表示恒等（仅在粘贴允许）。
2. `sm_transform_strokes`：按索引原位变换，时间戳 / 压力 / `flags` 不变，线宽按 `√|det|`，一次调用一个撤销条目，任何一点越界即整次失败。
3. `sm_copy_strokes`：只读导出选区为格式 1 快照字节，容量语义与 `sm_save` 一致。
4. `sm_paste`：只接受格式 1，可选变换，追加到最上层，一次调用一个撤销条目，预算与原子性按 M6 规则。
5. 编辑历史新增“整批插入”条目；变换复用 M5 的“按下标替换”。
6. C ABI 新增 3 个导出与 features bit 5；C# 新增 `TransformStrokes` / `CopyStrokes` / `PasteStrokes` 与托管 `Transform` 结构；加载时核对 bit 0–5。
7. C 示例、C# 静默宿主、SDK 构建与验收脚本同步更新。
8. 便签验证器加入“移动所选 / 复制 / 粘贴”三个动作，用引擎的变换与剪贴板字节实际跑一遍。

## 验收

- 变换：五类矩阵的手算真值、线宽缩放、样本元数据不变、索引与 z 序不变、空选区空操作、非法矩阵、越界与线宽溢出原子失败、活动笔划与 stale revision、重复索引、单条撤销重做。
- 复制：解码自校验、空选区、容量不足、查询模式、非法索引、只读性。
- 粘贴：复制→粘贴往返、带变换粘贴、置顶与顺序、单条撤销重做、格式 2 拒绝、截断 / 未知魔数 / 未知版本、空快照、预算超限、活动笔划、跨文档粘贴。
- 原 M0–M6 测试断言与共享夹具不改动，全部保持通过。
- fmt / workspace test / clippy -D warnings / release 通过；SDK 独立目录 C 动态、静态与 C# 宿主实际运行通过。
- 不声称实机拖拽手感、变换性能或触控目标尺寸已达标。

## 止损与边界

不实现系统剪贴板、交互式变换手柄、形状规整、视口旋转、预测笔迹、多页管理、Android、MSVC / UWP；不修改 PezMax-One、不建 submodule、不推送或发布。变换手柄的命中、吸附与撤销合并策略由宿主决定。
