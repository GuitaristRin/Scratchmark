# M11 实验规格：逐点轴向（倾斜与朝向）

状态：Canon，仅约束当前实验。SDK 0.1.0，ABI 1，快照新增格式 3；M0–M10 的既有接口与行为保持不变（参 `M0.md`…`M10.md`）。不承诺稳定发布兼容。

## 背景与能力位

主流移动便签的输入每点除了坐标与压力，还携带**倾斜**（`AXIS_TILT`）与**朝向**（orientation，弧度）：
手写输入每点通常包含 `x, y, pressure, tilt, orientation, dt` 六项
Scratchmark 的 `SmSample` 只有压力，因此补一条**轴向通道**。

- `sm_features()` 新增 bit 9（`SM_FEATURE_STYLUS_AXES = 1<<9`）。

## 轴向通道

```c
typedef struct SmSampleAxes {
    float tilt;        /* 弧度，0 表示与屏幕垂直或未提供；值域 [0, π/2] */
    float orientation; /* 弧度，值域 [-π, π] */
} SmSampleAxes;

SmStatus SM_CALL sm_append_axes(SmHandle handle, const SmSample *samples,
    const SmSampleAxes *axes, uint32_t count);
SmStatus SM_CALL sm_read_axes(SmHandle handle, uint64_t revision, uint32_t index,
    uint32_t start, SmSampleAxes *out_axes, uint32_t capacity, uint32_t *out_written);
```

- `sm_append_axes` 一次写入坐标与轴向，两数组长度都由同一个 `count` 决定；指针、批上限、时间非递减与错误码规则沿用 M0 的 `sm_append`。
- 轴向校验：两个分量都必须有限，`tilt ∈ [0, π/2]`，`orientation ∈ [-π, π]`；违反返回 `INVALID_ARGUMENT`，且整批不写入（与 M0 的原子性一致）。
- `sm_read_axes` 的分段 / 容量 / `STALE_REVISION` 语义与 `sm_read_points` 完全一致，输出与点一一对应。
- 用 `sm_append` 写入的样本，其轴向为 `(0, 0)`；`0` 同时表示“与屏幕垂直”与“设备未提供”两种情况，引擎不区分（鼠标与手指在这个意义上是垂直的）。

## 轴向的传播

| 操作 | 轴向行为 |
| --- | --- |
| `sm_erase_path` 切分 | 保留原样本轴向；切点按两侧样本线性插值（角度不做环绕处理，值域内插值） |
| `sm_transform_strokes` | 原样保留（倾斜 / 朝向是设备姿态，不是页面几何） |
| `sm_regularize_stroke` | 生成笔划轴向归零（理想几何没有手写姿态） |
| `sm_copy_strokes` / `sm_paste` | 随字节往返保留 |
| `sm_erase_stroke` / `sm_erase_indices` / `sm_clear` | 无影响 |
| `sm_hit_test` / `sm_lasso_hits` / `sm_predict` | 不读取轴向（判定仍只用中心线） |

## 快照格式 3

- 魔数 `SCRATCH3`（8 字节），头为 u32 版本（3）、u32 笔划数、u64 页面标识，其后台每笔与格式 2 逐字节相同，**每个样本在 `flags` 之后追加 4 字节 `tilt` 与 4 字节 `orientation`（小端 f32）**。
- `sm_save` 的格式选择：**任一已提交笔划带有非默认轴向** → 格式 3；否则保持既有规则（有页面标识写格式 2，没有写格式 1）。这样没有用轴向的文档仍能被旧宿主读取。
- `sm_load` 接受格式 1 / 2 / 3；格式 1 / 2 载入后轴向全为默认值。格式 3 的轴向按上面的值域校验，违反返回 `INVALID_DATA`。
- `sm_copy_strokes`：选区内任一 `sm_append_axes` 写入过笔划时产出**格式 3 且页面标识为 0**，否则仍是格式 1。`sm_paste` 接受格式 1，或**页面标识为 0 的格式 3**；其余（含格式 2、带页面标识的格式 3）仍按 M7 的语义拒绝为 `INVALID_DATA`。

## 验收边界

- 追加 / 读取往返（含活动笔划索引、分段读取、越界与容量不足）；轴向非法值（越界、负倾斜、非有限）整批拒绝且不写入。
- 格式选择：无轴向 → 1；有页面标识无轴向 → 2；有轴向 → 3；载入 1 / 2 后轴向为默认值；格式 3 往返保持轴向、点与时间不变。
- 传播：切分插值后的轴向、变换保留、规整归零、复制粘贴往返、格式 3 带页面标识被粘贴拒绝。
- 原 M0–M10 断言与共享夹具不改动，全部保持通过。**一处例外并已记录**：M3 的 `SCRATCH3` “未知魔数”用例改为真正未知的 `SCRATCH9`，同一断言意图保留，并新增“SCRATCH3 声明版本 2 → `UNSUPPORTED_VERSION`”用例。
- 不实现倾斜对手感的映射（笔锋、纹理、宽度补偿）、朝向驱动的笔形、压感与倾斜的联合曲线；不声称倾斜输入在实机上可用。

## 范围与边界

轴向是**输入元数据**，不是新的几何：命中、擦除、预测、形状规整都不改判定方式；引擎不解释它的物理含义，也不提供倾斜→笔宽的默认映射（那是宿主的手感策略）。
