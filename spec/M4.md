# M4 实验规格：命中测试与整笔擦除

状态：Canon，仅约束当前实验。SDK 0.4.0，ABI 1，快照格式仍为 1 / 2；M0 / M2 / M3 的既有接口、原始样本、派生几何、页面标识与视口行为保持不变。

## 能力位

- `sm_features()` 新增 bit 2（`SM_FEATURE_HIT_ERASE = 1<<2`），表示本规格的命中测试与整笔擦除能力。
- 新旧宿主按位核对；缺少该位的旧库不得被新绑定误用。

## 命中测试

```c
SmStatus sm_hit_test(SmHandle handle, uint64_t revision,
    double x, double y, double tolerance,
    uint32_t *out_index, uint32_t *out_found);
```

- 只在已提交笔划中查找，**不包含活动笔划**；命中测试本身不要求空闲，也不改变 revision、缓存或文档。
- `x`、`y` 必须有限且绝对值不超过 1e9；`tolerance` 必须有限且在 `[0, 1e9]`。否则返回 `INVALID_ARGUMENT`，不写输出。
- `revision` 必须等于当前 revision，否则返回 `STALE_REVISION`，不写输出。
- 命中判定使用**原始中心线**（不是 M2 派生平滑轨迹）：点到折线的最短距离 `d` 满足
  `d <= stroke.width / 2 + tolerance` 即命中；单点笔划按点到点距离计算。
- 多个笔划同时命中时，选择**最上层**者，即已提交笔划列表中索引最大者（后绘制者覆盖先绘制者）。这是擦除工具的预期语义。
- 成功时写入：
  - `out_found = 1` 且 `out_index = 命中的笔划索引`；或
  - `out_found = 0` 且 `out_index = 0`。
- 输出指针必须有效、对齐且互不重叠；错误时不写入。空文档成功返回 `found=0`。

## 整笔擦除

```c
SmStatus sm_erase_stroke(SmHandle handle, uint64_t revision, uint32_t index);
```

- 仅在没有活动笔划时可用；有活动笔划返回 `INVALID_STATE`，不改变状态。
- `revision` 必须等于当前 revision，否则返回 `STALE_REVISION`。
- `index` 必须小于当前已提交笔划数，否则返回 `INVALID_ARGUMENT`。
- 成功时删除该整笔，递增 revision，清除重做历史，并把这次删除压入撤销历史。
- 撤销恢复该笔到**原索引**（保持 z 序）；重做再次删除同一索引。撤销 / 重做仍只在空闲时可用。
- 删除不改变“含历史在内”的笔划 / 点数预算：被删笔划仍由撤销历史持有；后续 finish 清除重做历史时才释放对应预算。
- 快照仍只保存当前已提交笔划，不含撤销 / 重做历史；load 后重做历史清空，载入笔划可按整笔逐笔撤销（沿用既有宿主行为），但不能撤销到 load 之前的文档。
- 擦除不修改页面标识；页面标识规则沿用 M3。

## 历史与状态语义

- 统一编辑历史包含“新增笔划”和“删除笔划”两种操作，按发生顺序撤销 / 重做。
- `can_undo` / `can_redo` 仅在空闲且对应历史非空时为 1。
- finish 成功后清除重做历史；cancel 保留原撤销 / 重做历史。
- 任何失败操作不递增 revision、不改变文档、不改变历史或缓存。
- 资源上限仍为含历史在内最多 1,000,000 点、100,000 笔划；超出时 `begin` 返回 `LIMIT_EXCEEDED`，append 规则沿用 M0。

## 验收边界

- 命中：点在线段上、线段端点、折线拐角、单点、容差边界、宽度边界、上层优先、活动笔划排除、空文档、stale revision、非法坐标 / 容差、输出不写。
- 擦除：索引边界、活动笔划拒绝、stale revision、撤销恢复原 z 序、重做再删除、finish 清空重做、cancel 保留历史、快照只含存活笔划、load 后重做清空且载入笔划可整笔撤销。
- C ABI 与 C# 绑定实际调用；C 动态 / 静态宿主与独立 SDK 验收沿用既有流程。
- 不声称实机擦除手感、命中性能或触控目标尺寸已达标；这些需要真实设备与宿主验证。
