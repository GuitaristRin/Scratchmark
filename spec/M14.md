# M14 实验规格：按笔宽的点间距重采样

状态：Canon，仅约束当前实验。SDK 0.1.0，ABI 1，快照格式仍为 1 / 2 / 3；M0–M13 的既有接口与行为保持不变。不承诺稳定发布兼容。

## 背景与能力位

铺笔触需要按固定步距取点，步距随笔宽变化。

Scratchmark 的 M2 只做“逐样本因果平滑 + 逐点笔宽”，**没有按间距重采样**；宿主若要按固定步距铺笔触，只能自己算。
本规格补一个只读的重采样查询：按 `间距 = 笔宽 × 比例` 沿中心线等距取点，并把 M2 的逐点笔宽一起给出来。

- `sm_features()` 新增 bit 12（`SM_FEATURE_RESAMPLE = 1<<12`）。

## 接口

```c
typedef struct SmResampleOptions {
    double spacing_ratio; /* 间距 = 笔宽 × 该比例；必须有限且 > 0 */
    SmBrushOptions brush; /* 与 M2 相同：决定输出点的逐点笔宽 */
    uint32_t reserved;    /* 必须为 0 */
} SmResampleOptions;

SmStatus SM_CALL sm_resample_stroke(SmHandle handle, uint64_t revision, uint32_t index,
    const SmResampleOptions *options,
    SmBrushPoint *out_points, uint32_t capacity, uint32_t *out_written);
```

- 读取已提交笔划；`index == stroke_count` 时读活动笔划（与 `sm_read_points` 一致）。`revision` 不匹配返回 `STALE_REVISION`。
- 只读：不改变 revision、文档、历史与缓存以外的东西（允许复用 M2 的派生缓存）。
- **间距**：`spacing = 笔宽 × spacing_ratio`。`spacing_ratio` 必须有限且 `> 0`；算出的 `spacing` 必须是有限正数，否则 `INVALID_ARGUMENT`。
- **取点规则**：从笔划首点起，沿中心线按弧长每隔 `spacing` 取一点；**末尾总是包含原始末点**（最后一小段即使短于间距也保留），因此结果首点等于原始首点、末点等于原始末点。
- 单点笔划返回 1 个点；所有点重合的退化笔划同样返回 1 个点。
- 输出 `SmBrushPoint`：坐标是该位置的页面坐标，`width` 是该位置按 `options.brush` 计算的逐点完整笔宽（在相邻两个派生点之间线性插值）。
- 需要的点数超过 `capacity` 时返回 `BUFFER_TOO_SMALL` 并把所需数量写入 `out_written`，不写数组；`capacity == 0` 与 `out_points == NULL` 组合只用于查询数量。
- 点数上限沿用 `MAX_POINTS`（1,000,000）；`spacing` 过小导致超限时返回 `LIMIT_EXCEEDED`。
- 失败不写输出（`BUFFER_TOO_SMALL` 例外：它写所需数量）。

## 验收边界

- 直线：`spacing` 取 1 / 0.6 / 2.5 时点数与坐标逐一手算一致；末点等于原始末点。
- 笔宽加倍 → 间距加倍 → 点数约减半（同一比例）。
- 拐角笔划：跨段连续，段间不重复取点（顶点处不产生重复点）。
- 单点 / 重合点 / 两段不等长：点数与切点位置符合“按弧长等距 + 保留末点”。
- 压力笔划：输出点的 `width` 与 M2 派生笔宽在同一位置一致（相邻派生点线性插值）。
- 非法 `spacing_ratio`（0、负、非有限）、非法 `brush`、`reserved ≠ 0`、`STALE_REVISION`、`INVALID_HANDLE`、容量不足与查询模式、点数超限。
- 原 M0–M13 断言与共享夹具不改动，全部保持通过。
- 不实现按笔型的纹理铺贴、虚线、笔触压感密度（这些是渲染）；不声称重采样后的观感在实机上已验收。

## 范围与边界

重采样是**只读派生**：不改原始样本、不进快照、不影响命中判定与编辑语义；宿主可以只用它铺笔触，也可以完全不用。
