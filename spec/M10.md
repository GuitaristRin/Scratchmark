# M10 实验规格：预测笔迹

状态：Canon，仅约束当前实验。SDK 0.10.0，ABI 1，快照格式仍为 1 / 2；M0–M9 的既有接口与行为保持不变（参 `M0.md`…`M9.md`）。不承诺稳定发布兼容。

## 能力位

- `sm_features()` 新增 bit 8（`SM_FEATURE_PREDICTION = 1<<8`）。

## 定位

预测**不是**文档内容：它只根据活动笔划已经收到的样本外推一小段尾迹，供宿主在下一批真实样本到达前先行显示。
预测不写入文档、不进入快照、不改变 revision，也不参与命中 / 擦除 / 选区。

## 接口

```c
/* 复用 M2 的笔刷配置，保证预测尾迹与已绘制部分的笔宽一致。 */
typedef struct SmPredictionOptions {
    double horizon_us;   /* 向前外推的时间窗，微秒 */
    double max_distance; /* 预测尾迹的最大长度，页面单位 */
    uint32_t count;      /* 需要几个预测点，1..64 */
    uint32_t reserved;   /* 必须为 0 */
    SmBrushOptions brush;
} SmPredictionOptions;

SmStatus SM_CALL sm_predict(SmHandle handle, uint64_t revision,
    const SmPredictionOptions *options,
    SmBrushPoint *out_points, uint32_t capacity, uint32_t *out_written);
```

- `revision` 必须等于当前 revision，否则 `STALE_REVISION`（预测只在“当前这一笔”上有意义）。
- `options`：`horizon_us` 有限且 `> 0`；`max_distance` 有限且 `> 0`；`count` 在 `1..=64`；`reserved = 0`；`brush` 按 M2 规则有效。违反返回 `INVALID_ARGUMENT`。
- 输出 `SmBrushPoint`（与 M2 相同的 x / y / width），**升序**从笔尖向前。
- 容量不足返回 `BUFFER_TOO_SMALL` 并把所需数量写入 `out_written`，不写数组；命中为零（无预测）是 `OK` 且 `out_written = 0`。
- 没有活动笔划、活动笔划少于 2 点、或尾段样本时间跨度不为正时，返回 `OK` 且不产生点——宿主每帧轮询不该被当作出错。

## 外推模型（确定性）

1. 取活动笔划**最后至多 8 个样本**作为尾段；尾段速度 `v_tail = (p_last − p_first) / (t_last − t_first)`（页面单位 / 微秒）。
2. 最近两点速度 `v_pair = (p_last − p_prev) / (t_last − t_prev)`；`v_pair` 的时间跨度不为正时取 `v_tail`。
3. 合成速度 `v = 0.5·v_tail + 0.5·v_pair`（固定权重，不引入可调参数）。
4. 长度上限：若 `|v|·horizon_us > max_distance`，按比例把 `v` 缩小到恰好 `max_distance`。
5. 第 `i` 个点（`i = 1..count`）为 `p_last + v·horizon_us·(i / count)`。
6. 任一预测点越出页面域（绝对值 > 1e9）时**在该点截断**，不报错——预测是提示，宁可少画。
7. 笔宽 `width` 取活动笔划按 `options.brush` 计算出的**最后一个笔刷点的宽度**，整段预测保持这个宽度（不做压力外推）。

## 宿主责任

- 预测点与真实笔迹分开绘制（例如半透明或细线），下一批真实样本到达后立即丢弃预测；引擎不保存预测、不自动清理。
- 预测不改变任何编辑语义：`finish` / `cancel` / 撤销 / 命中 / 擦除都看不到预测点。
- 预测是**可选**优化：宿主不调用时行为与 M9 完全一致。

## 验收边界

- 匀速直线：预测点沿原方向、间距按 `horizon/count` 等比、点数等于 `count`。
- 拐弯：预测方向落在尾段与最近两点速度的合成方向上（手算真值）。
- 长度上限：极快笔划下总位移恰好 `max_distance`。
- 无活动笔划 / 单点笔划 / 时间跨度为零：`OK` 且零预测点。
- 笔宽：压力笔划的预测宽度等于该笔按同一配置的最后一个笔刷宽度。
- 越界截断：极端速度下预测点不出页面域，且点数按截断减少。
- 非法选项、容量不足、查询模式、`STALE_REVISION`、`INVALID_HANDLE`；预测不改变 revision、文档、历史与快照。
- 原 M0–M9 断言与共享夹具不改动，全部保持通过。
- 不实现预测的机器学习模型、输入延迟补偿策略、预测与真实笔迹的融合渲染、历史点批处理；不声称实机延迟改善已达标。
