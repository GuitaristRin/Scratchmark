# M17 实验规格：擦除切点标记

状态：Canon，仅约束当前实验。SDK 0.1.0，ABI 1，**快照格式仍为 1 / 2 / 3**（`flags` 本来就在样本里，不新增字段）；M0–M16 的既有接口与行为保持不变。不承诺稳定发布兼容。

## 背景与能力位

用户两次反馈“局部擦除看起来很奇怪”：擦完是**断成两截、垂直平口**。原因不是 bug，而是语义与架构：

- 同类产品的擦除是**几何标记 + 渲染侧丢弃**：擦除作用在点序列上，
  由渲染丢掉被标记的区段，圆缺口是渲染的结果而不是位图擦除。
  也就是说：**同类产品的数据也是几何，圆缺口来自渲染**。
- Scratchmark 只给「中心线 + 标量笔宽」，宿主画多边形，切口自然是垂直平口。

因此补的不是“像素擦”，而是**让宿主知道哪一端是擦出来的**：切点打标记，宿主对带标记的端点画圆头/缺口，其余端点保持原样。
这样既不动几何表示，也不动快照格式。

- `sm_features()` 新增 bit 15（`SM_FEATURE_CUT_MARK = 1<<15`）。

## 样本 `flags` 的语义扩展

`SmSample.flags` 目前只有两种取值（`spec/M0.md`）：`0` = 无压力，`1` = 有压力。本规格把它扩成**位域**：

| 位 | 含义 |
| --- | --- |
| bit 0（值 1） | 该点带真实压力（沿用 M0 语义，`pressure ∈ [0,1]`；不带压力时 `pressure` 必须为 0） |
| bit 1（值 2） | **该点是擦除切出来的端点**（擦除路径切断笔划时由引擎打出） |
| 其余位 | 必须为 0，否则 `INVALID_ARGUMENT` / `INVALID_DATA` |

- `flags = 2`（只有切点标记）时 `pressure` 必须为 0；`flags = 3` 表示“切点且带压力”。
- 校验规则：`flags & !0b11 != 0` → 拒绝；`flags & 1 == 0` 时 `pressure` 必须为 0，否则拒绝。
- **兼容性**：既有文档里的 `flags` 只有 0 / 1，落到新规则仍然合法，`sm_load` 与格式 1 / 2 / 3 都不需要改；
  `sm_append` 也不接受调用方写 bit 1（写入通道只允许 0 / 1），切点标记**只能由引擎在擦除时产生**。
  这样宿主不能伪造切点，标记的语义保持单一来源。

## 标记规则

- `sm_erase_path` 把一笔切成片段时：**片段两端若由擦除产生**（即该点是切割插值出来的新端点，而不是原始笔划的端点），
  就置 bit 1；原始笔划自己的首末点即使成为片段端点也**不标记**。
- 片段内部的点保持原有 `flags`（不新增标记）。
- `sm_erase_stroke` / `sm_erase_indices` / `sm_clear` 不产生标记（整笔消失）。
- `sm_transform_strokes` / `sm_translate_all` / `sm_copy_strokes` / `sm_paste` / 快照往返都**原样保留**标记。
- `sm_regularize_stroke` 生成的是理想几何，标记归零。
- 命中、预测、重采样都不读 bit 1；预测点沿用最后一个笔刷点的 `flags`（与 M10 一致）。

## 宿主侧约定

- 渲染时：对片段端点，若 `flags & 2 != 0`，按圆头（或按擦除半径的缺口）收尾；否则保持原来的端帽。
- 引擎不提供“缺口形状”：圆头半径、缺口角度都属渲染策略，宿主可用 M14 的重采样与 M2 的逐点笔宽自行组合。
- `sm_read_points` 是唯一读取通道：不需要新导出。

## 验收边界

- 切分后：被切出的端点带 bit 1，原始首末点不带；片段内部的点标记不变。
- 一次擦除产生多个片段时，每个片段的切口都带标记；两条片段共用的切点各自独立标记。
- 变换 / 平移 / 复制粘贴 / 快照往返后标记不变；规整后归零。
- `sm_append` 收到 `flags = 2` 或 `3` 时返回 `INVALID_ARGUMENT`（写入通道不允许伪造切点）。
- 载入 `flags` 越界（`& !0b11 != 0`）或 bit0 未置位却带压力的旧文件 → `INVALID_DATA`。
- 既有 M0–M16 断言与共享夹具全部保持通过（它们的 `flags` 都是 0 / 1）。
- 不实现像素擦、缺口几何、端帽形状；不声称观感与 参考实现 逐像素一致。

## 范围与边界

切点标记是**渲染提示**，不是新几何：它不改判定、不改快照布局、不改变片段数量；去掉标记引擎行为与 M5 完全相同。
