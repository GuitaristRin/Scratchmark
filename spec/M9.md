# M9 实验规格：视口旋转与视口辅助

状态：Canon，仅约束当前实验。SDK 0.1.0，ABI 1，快照格式仍为 1 / 2；M0–M8 的既有接口与行为保持不变（参 `M0.md`…`M8.md`）。不承诺稳定发布兼容。

## 能力位

- `sm_features()` 新增 bit 7（`SM_FEATURE_VIEWPORT_ROTATION = 1<<7`）。
- M3 的 `SmViewport` 与五个旧导出**完全不变**（等价于旋转角为 0）；旋转走新增的结构与导出，旧宿主不受影响。

## 扩展视口

```c
typedef struct SmViewportEx {
    double scale, angle, offset_x, offset_y;
    uint32_t reserved;
} SmViewportEx;
```

- 页面点 → 视口点（先缩放、再旋转、最后平移）：
  - `vx = scale·(cos·px − sin·py) + offset_x`
  - `vy = scale·(sin·px + cos·py) + offset_y`
  其中 `cos/sin` 取 `angle`（弧度）。
- 逆变换：`page = R(−angle)·((view − offset) / scale)`。
- 校验：`scale` 有限且 `> 0`；`angle`、`offset` 有限；`reserved` 必须为 0；否则 `INVALID_ARGUMENT`。角度的绝对值不设上限（等价于对 `2π` 取模），但必须是有限值。
- 映射结果必须有限；`sm_page_to_viewport_ex` 的输入须在页面域（绝对值 ≤ 1e9），`sm_viewport_to_page_ex` 的输出须落回页面域，否则 `INVALID_ARGUMENT`；失败不写输出。
- 线宽与命中容差只随 `scale` 缩放，与旋转无关。
- `sm_bounds_page_to_viewport_ex`：把页面轴对齐矩形映射成**旋转后的轴对齐外接矩形**（四个角变换后取最小 / 最大），因此结果通常比原矩形大。

## 导出

```c
SmStatus SM_CALL sm_page_to_viewport_ex(const SmViewportEx *viewport,
    const SmPoint *in, SmPoint *out);
SmStatus SM_CALL sm_viewport_to_page_ex(const SmViewportEx *viewport,
    const SmPoint *in, SmPoint *out);
SmStatus SM_CALL sm_width_page_to_viewport_ex(const SmViewportEx *viewport,
    double width, double *out_width);
SmStatus SM_CALL sm_width_viewport_to_page_ex(const SmViewportEx *viewport,
    double width, double *out_width);
SmStatus SM_CALL sm_bounds_page_to_viewport_ex(const SmViewportEx *viewport,
    const SmBounds *in, SmBounds *out);

/* 以视口点为锚缩放：锚点下的页面点保持不变。 */
SmStatus SM_CALL sm_viewport_ex_zoom_at(const SmViewportEx *viewport,
    const SmPoint *anchor, double factor, SmViewportEx *out_viewport);

/* 让页面边界适配视口矩形：按旋转后的外接框等比缩放并居中。 */
SmStatus SM_CALL sm_viewport_ex_fit(const SmBounds *page_bounds,
    double view_width, double view_height, double angle, double padding,
    SmViewportEx *out_viewport);
```

- `sm_viewport_ex_zoom_at`：`factor` 必须有限且 `> 0`；新 `scale = scale·factor` 必须有限且 `> 0`；`offset' = anchor − (anchor − offset)·factor`（锚点下的页面点保持不变，与旋转角无关）。失败不写输出。
- `sm_viewport_ex_fit`：`page_bounds` 的 `min ≤ max` 且四值有限；`view_width`、`view_height` 必须有限且 `> 0`；`padding` 有限且 `>= 0` 且小于视口短边的一半；`angle` 有限。缩放取
  `scale = min((view_width − 2·padding)/框宽, (view_height − 2·padding)/框高)`（框为页面矩形按 `angle` 旋转后的外接框），必须有限且 `> 0`；偏移把页面中心映射到视口中心。失败不写输出。

## 与旧接口的关系

- 旧 `sm_page_to_viewport` 等五个导出语义不变，等价于 `angle = 0` 的扩展版本；同一 `scale/offset` 下两者结果逐位相同。
- 引擎仍然不拥有视口、不做手势：旋转中心、吸附角度、双指手势与惯性由宿主决定；引擎只保证“同一份视口用于输入与显示”时笔迹与页面内容对得上。

## 验收边界

- 旋转 0° / 90° / 180° / 45° / 负角 / 大于 2π 的等价角：与手算值一致；往返误差 ≤ 1e-9。
- 旋转下 `width` 只随 `scale`；`bounds` 外接框在 90° 时宽高互换、45° 时按 √2 放大。
- 非法输入：`scale ≤ 0` / 非有限、`angle` 非有限、`reserved ≠ 0`、页面域越界、`factor ≤ 0`、`padding` 越界、视口尺寸 ≤ 0、`page_bounds` 反序；全部不写输出。
- `zoom_at`：任意角度下锚点下的页面点保持不变；连续两次缩放等价于一次合成缩放（1e-9）。
- `fit`：0° 与 90° 下页面框落在视口内、居中、内边距生效；退化页面（零宽零高）与过大的 `padding` 被拒绝。
- 原 M0–M8 断言与共享夹具不改动，全部保持通过。
- 不实现旋转手势、惯性、吸附、非等比视口缩放、“整页旋转后写入”的坐标换算策略；不声称实机旋转显示效果已验收。
