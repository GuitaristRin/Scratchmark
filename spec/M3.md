# M3 实验规格：页面标识与视口变换

状态：Canon，仅约束当前实验。SDK 0.3.0，ABI 1。快照在格式 1 之外新增格式 2；原接口、原始样本、派生几何与 M0/M2 行为保持，参 `M0.md`、`M2.md`；不承诺稳定发布兼容。

## 页面标识

- 一个引擎文档仍是一页。页面标识（page id）为宿主选择的 u64 稳定键，把引擎 / 快照与业务页面对应；0 表示未设置。引擎不解释、不索引该值，页面标识不是坐标。
- `sm_get_page_id(handle, out)`：返回当前页面标识；句柄无效返回 INVALID_HANDLE，输出指针无效返回 INVALID_ARGUMENT。
- `sm_set_page_id(handle, id)`：仅在空闲（无活动笔划）时可用，否则 INVALID_STATE。新值等于当前值时成功且 revision 不变；不同则写入并递增 revision。撤销 / 重做 / 取消不回退页面标识；load 按下节整份替换。
- 页面标识不进入 SmState（结构不变）；宿主经显式读取获取。

## 页面坐标与视口坐标

- 样本、派生点与边界都是页面局部坐标，域与 M0 相同：有限且绝对值不超过 1e9。视口坐标由宿主定义（通常是屏幕像素），只要求有限。
- `SmViewport`：f64 scale、offset_x、offset_y，u32 reserved，自然对齐，大小 32。映射逐轴为 `viewport = page * scale + offset`，逆映射 `page = (viewport - offset) / scale`；线宽按同 scale 缩放。scale 覆盖缩放与 DPI，旋转 / 翻转由宿主自理，不在本层。
- `SmPoint`：f64 x、y，大小 16。`SmBounds`：f64 min_x、min_y、max_x、max_y，大小 32。
- 校验：scale 有限且 > 0，offset 有限，reserved 必须 0；否则 INVALID_ARGUMENT。
- 导出均为无句柄纯函数，无缓存、无状态，失败不写输出：
  - `sm_page_to_viewport(vp, in, out)`：页面点→视口点；输入须在页面域。
  - `sm_viewport_to_page(vp, in, out)`：视口点→页面点；输入有限，输出须落回页面域。
  - `sm_width_page_to_viewport(vp, width, out)` / `sm_width_viewport_to_page(vp, width, out)`：线宽与命中容差缩放；输入须有限正，输出须有限正。
  - `sm_bounds_page_to_viewport(vp, in, out)`：scale > 0 时角序不变，两角直接映射。
- 输入非有限、页面域输入 / 输出越界、结果溢出为非有限或下溢为 0，一律 INVALID_ARGUMENT。指针 NULL / 不对齐按 M0 规则。`sm_features` 新增 bit 1（`SM_FEATURE_PAGE_VIEWPORT`）表示本节能力；其他位宿主忽略。

## 缩放 / 平移一致性

- 输入路径：宿主把视口输入经 `sm_viewport_to_page` 变成页面样本再 append；显示路径：读取页面几何经 `sm_page_to_viewport` 得到视口几何。两条路径必须使用同一 SmViewport，笔迹才与页面内容对齐；roundtrip 误差为一次乘除的浮点舍入，不保证逐位还原。
- 命中容差先用 `sm_width_viewport_to_page` 换算到页面域再比较；引擎本轮仍不提供命中 / 擦除 API。SmViewport 与 M2 读取配置一样由宿主保存：不写入快照，变化也不影响 revision。

## 快照

- 格式 2 使用独立魔数 `SCRATCH2`（8 字节），头为 u32 版本（2）、u32 笔划数、u64 页面标识（小端），其后每笔与格式 1 逐字节相同。格式 1 的魔数与语义完全不变，仅接受版本 1；未知魔数沿用 INVALID_DATA，已知魔数的未知版本返回 UNSUPPORTED_VERSION。（M11 起新增格式 3 `SCRATCH3`，参 `spec/M11.md`；本节的格式 1 / 2 语义不变。）
- 设置了页面标识的文档 save 写格式 2；未设置的仍写格式 1，旧宿主可继续读取。
- load 整份验证后整份替换：格式 1 的页面标识视为 0；快照页面标识为 0 时清空当前标识；当前标识与快照标识都非零且不同时返回 INVALID_DATA 且原文档不变，防止跨页混入。
- 快照仍不含 SmViewport、平滑 / 压力配置与 revision；视口与显示配置由宿主在自己的文档元数据中保存。

## 范围与验收边界

页面标识只是稳定键，不做页面列表、多页管理与业务文档模型；视口是纯数学，不含手势、输入预测或非线性变形。旋转、擦除、套索、命中 API、每笔历史视口不在本轮。测试以手算真值、往返一致性与真实库输出为准；不声称实机手感或显示性能。
