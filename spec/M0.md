# M0 实验规格

状态：Canon，仅约束本阶段实验实现。SDK 0.1.0，ABI 标识 1，快照格式标识 1。正式发布前均可变更；宿主必须固定匹配版本。C 声明唯一维护在 [scratchmark.h](../include/scratchmark.h)。

后续 SDK 0.2.0 的派生笔刷扩展见 [M2](M2.md)，本规格所定义的原始点、固定线宽读取与快照字节不变；下面的未实现范围指 M0 阶段。

## 状态与输入

- 引擎为独立文档，零个或多个已提交笔划，至多一个活动笔划。所有坐标均为宿主给定的同一页面局部坐标，不含屏幕 / DPI 转换。
- 固定线宽为有限正数且不超过 1,000,000，颜色为 `0xRRGGBBAA`。折线连接输入点，端点 / 连接的圆形覆盖半径为宽度一半；单点为圆点。引擎返回中心线及宽度和保守边界，光栅化由前端完成。
- Sample 的坐标有限且绝对值不超过 1,000,000,000；时间为微秒整数，在一条笔划内非递减。
- Sample flags 仅支持 bit 0（真实压力可用）；可用时 pressure 为有限的 [0,1]，不可用时 flags / pressure 均为 0。M0 记录压力，但线宽不随压力变化。
- 输入批次至多 65,536 点；空批次在有活动笔划时合法。一个引擎含历史在内至多 1,000,000 点、100,000 笔划；这些是实验资源上限，不是产品性能指标。
- begin 在空闲时创建活动笔划；append 整批先验证，失败不接受任何点。finish 必须有非空活动笔划，成功才清除重做历史；cancel 丢弃活动笔划但保留原有重做历史。
- undo / redo 仅在没有活动笔划时可用，按整笔操作；无可撤销 / 重做对象返回 INVALID_STATE。M0 不实现擦除、套索和形状工具。

## 读取与并发

- revision 从 1 开始，每次成功且实际改变状态时递增；空 append 不改变 revision。undo / redo / load 不复用旧 revision，耗尽返回 LIMIT_EXCEEDED。
- 状态给出 revision、已提交笔划数量、活动笔划点数及标志、撤销 / 重做可用性。活动笔划存在时，占据最后一个读取索引，即已提交数量。
- 元数据给出点数、线宽、颜色、活动标志与边界；空活动笔划的边界为全零。
- 读取元数据 / 点必须传入获取状态时的 revision；不匹配返回 STALE_REVISION，不返回混合状态。点读取支持 start + capacity，最多复制剩余点数；start 超出点数返回 INVALID_ARGUMENT。
- 句柄为不复用的 uint64 ID，0 无效。destroy 后新操作返回 INVALID_HANDLE；同句柄操作串行，不同引擎可独立工作。destroy 前已进入的操作可能完成，宿主应自行协调销毁时序。
- 不回调宿主、不拥有窗口或线程、不保留调用方缓冲区指针。调用结束后宿主可重用输入 / 输出存储。

## 内存与失败

- 所有输出缓冲区由宿主分配 / 释放。样本输入被复制进引擎；没有“零复制”承诺。
- 指针在声明长度内必须有效、正确对齐、已初始化（输入）且互不重叠；输出在整个调用期间必须独占可写。引擎检查空值 / 对齐 / 大小，不能验证任意地址的真实性。
- 空输入允许 NULL；capacity 为 0 时允许 NULL 输出数组。所有标量输出指针必须有效，错误时不写入，save 的 BUFFER_TOO_SMALL 除外（写入所需字节数）。
- 状态码：OK=0、INVALID_ARGUMENT=1、INVALID_HANDLE=2、INVALID_STATE=3、BUFFER_TOO_SMALL=4、STALE_REVISION=5、INVALID_DATA=6、UNSUPPORTED_VERSION=7、LIMIT_EXCEEDED=8、INTERNAL=9。
- 常规错误用状态码；Rust unwind panic 在 ABI 层截获后返回 INTERNAL，发生 panic 的引擎可能不可继续使用，宿主应销毁。OOM、abort 与非法宿主指针不受此机制保护，动态库不是故障隔离边界。

## 快照

- save 只在无活动笔划时可用，仅含当前已提交笔划；不保存撤销 / 重做历史和 revision。NULL / 0 可查询大小，非空结果返回 BUFFER_TOO_SMALL 并填写 required。
- load 只在空闲时可用；整份验证成功后替换文档，清除历史并递增当前 revision，失败保持原文档。加载后可继续 begin / append / finish。
- 字节序固定小端；头为 8 字节 `SCRATCH\0`、u32 格式版本、u32 笔划数。每笔为 f64 宽度、u32 颜色、u32 点数；每点为 f64 x、f64 y、u64 时间、f32 压力、u32 flags。
- 空已提交笔划、非有限数、非法 flags、时间逆序、截断、尾随字节和超限一律拒绝。最大快照为 64 MiB，读取长度在分配 / 解码前检查；不从头部声明数量直接预分配无限内存。
- 这是内部实验交换格式，没有完整性校验 / 加密和长期兼容承诺；宿主负责持久存储的原子替换与保留上一份有效文件。

## 验证边界

折线与保守边界、状态转换、数据恢复及 C ABI 是本阶段验收对象。压力表现、抗锯齿、平滑、预测、防误触、帧呈现和设备手感未实现；不把单元测试或独立 C 加载成功描述为这些能力已通过。
