# M12 实验规格：文档边界、整份平移与页面尺寸归属

状态：Canon，仅约束当前实验。SDK 0.1.0，ABI 1，快照格式仍为 1 / 2 / 3；M0–M11 的既有接口与行为保持不变。不承诺稳定发布兼容。

## 背景与能力位

画布需要能**边写边增长**：向下加长（`dy < 0` 被拒绝），
`rolling / rollStart / rollEnd` 滚动视图，`getTopBlank / setTopBlank`、`getContentOffsetX/Y`、`getContentScale`、
画布高度、可见高度与最大高度描述几何，扩展类型区分“内容变化 / 滚动 / 加长”三种


其中**画布高度、顶部留白、内容偏移与滚动**都属于显示与页面布局；真正需要引擎提供的是两件事：
“现在内容占到哪儿”（宿主据此决定页面要多高）与“整份内容能不能一次平移”（画布从顶部加长时要把内容整体下移）。
本规格补这两件，并把页面尺寸明确划归宿主。

- `sm_features()` 新增 bit 10（`SM_FEATURE_PAGE_EXTENT = 1<<10`）。

## 文档边界

```c
SmStatus SM_CALL sm_document_bounds(SmHandle handle, uint64_t revision,
    SmBounds *out_bounds, uint32_t *out_strokes, uint32_t *out_found);
```

- 只统计**已提交笔划**，活动笔划不参与；结果包含笔宽（与 `sm_get_stroke` 的 `min/max` 同源）。
- `out_found = 0` 时（没有已提交笔划）`out_bounds` 写四个 0，`out_strokes` 写 0；`out_found = 1` 时给出并集边界与笔划数。
- 只读：不改变 revision / 文档 / 历史。`revision` 不匹配返回 `STALE_REVISION`；三个输出指针都必须有效，错误时不写入。

## 整份平移

```c
SmStatus SM_CALL sm_translate_all(SmHandle handle, uint64_t revision,
    double dx, double dy);
```

- 把**全部已提交笔划**按 `(dx, dy)` 平移，一次调用只产生**一个**撤销条目；`dx`、`dy` 必须有限，`|dx|,|dy| <= 1e9`。
- 平移后任一点越出页面域（绝对值 > 1e9）返回 `INVALID_ARGUMENT`，文档不变；线宽、颜色、时间戳、压力、`flags` 与轴向都不变。
- 只在空闲时可用（有活动笔划返回 `INVALID_STATE`）；`revision` 不匹配返回 `STALE_REVISION`。
- 没有已提交笔划时是空操作：`OK`，不递增 revision、不产生历史条目（与 M6 的空列表规则一致）。
- 语义等价于“用全 1 的索引列表调用 `sm_transform_strokes` 做纯平移”，但宿主不必枚举索引；实现对每个笔划按 M5 的“按下标替换”记录，因此撤销快照与原 z 序都保持。

## 页面尺寸归属（裁定）

- **画布 / 页面高度、顶部留白、内容偏移与滚动位置由宿主保留**，理由与 M3 的视口一致：它们是显示与布局参数，不是笔迹几何；引擎不保存、也不入快照。
- 宿主增长页面的做法：`sm_document_bounds` 拿到内容边界 → 决定新的页面高度（例如 `max(现高, 内容底边 + 留白)`）→ 若从顶部加长则再调 `sm_translate_all(0, 加长量)`。
- 因此**不新增快照格式**：`spec/M11.md` 的格式 3 仍只承载轴向；页面尺寸不进快照，重开后由宿主按 `sm_document_bounds` 重新计算或用自己的元数据恢复。

## 验收边界

- 边界：空文档 `found=0` 且四值 0；单笔 / 多笔并集；含笔宽；活动笔划不计入；`revision` 过期；输出指针无效时不写入。
- 平移：正负方向、整份一起动、一次撤销恢复、越界原子失败、活动笔划拒绝、空文档空操作、线宽与轴向不变、快照往返后坐标仍是平移后的值。
- 原 M0–M11 断言与共享夹具不改动，全部保持通过。
- 不实现页面尺寸持久化、滚动惯性、顶部留白计算、无限画布策略；不声称实机滚动手感或在超大文档上的性能。

## 范围与边界

引擎只回答“内容在哪、能不能整体挪”，不回答“页面该多高、滚到哪儿”。这条分工写进 `docs/HOST_INTEGRATION.md`，替代此前“画布扩展未实现”的含糊状态。
