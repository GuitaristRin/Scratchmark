# M7 实验规格：选区变换与复制粘贴

状态：Canon，仅约束当前实验。SDK 0.7.0，ABI 1，快照格式仍为 1 / 2；M0 / M2 / M3 / M4 / M5 / M6 的既有接口与行为保持不变（参 `M0.md`、`M2.md`、`M3.md`、`M4.md`、`M5.md`、`M6.md`）。不承诺稳定发布兼容。

## 能力位

- `sm_features()` 新增 bit 5（`SM_FEATURE_TRANSFORM = 1<<5`）。

## 变换矩阵

```c
typedef struct SmTransform {
    double m00, m01, m10, m11, dx, dy;
} SmTransform;
```

- 页面点映射：`x' = m00·x + m01·y + dx`，`y' = m10·x + m11·y + dy`。平移、缩放、旋转、镜像、剪切都可用它表达；行列式为负表示镜像。
- 校验：六个系数必须有限；`det = m00·m11 - m01·m10` 必须有限且 `1e-12 <= |det| <= 1e12`，否则 `INVALID_ARGUMENT`。**不**接受退化矩阵（`det == 0`）。
- 结构体内不含保留字段，大小 48，自然对齐；`NULL` 在允许的位置表示恒等变换。

## 原位变换选区

```c
SmStatus sm_transform_strokes(SmHandle handle, uint64_t revision,
    const uint32_t *indices, uint32_t count, const SmTransform *transform);
```

- 只在空闲时可用；有活动笔划返回 `INVALID_STATE`。`revision` 不匹配返回 `STALE_REVISION`。
- `indices` 规则与 M6 的批量删除一致：全部 `< stroke_count`、不得重复，顺序任意（引擎排序）。
- `count == 0` 是空操作：`OK`，不递增 revision、不产生历史条目。
- `transform` 不可为 `NULL`（原位变换没有意义的空操作）。
- 每个被选笔划的所有原始样本按矩阵变换；时间戳、压力与 `flags` **不变**；笔划颜色不变；线宽按 `√|det|` 缩放（各向异性缩放只能用一个标量宽度近似，这里取等面积因子）。
- 原子性：若任一点变换结果非有限、绝对值超过 1e9，或缩放后的线宽非有限 / `<= 0` / `> 1e6`，整次调用返回 `INVALID_ARGUMENT` 且不改变文档。
- 成功时笔划仍在**原索引**，z 序不变；一次调用只产生**一个**撤销条目，并清除重做历史。

## 复制选区

```c
SmStatus sm_copy_strokes(SmHandle handle, uint64_t revision,
    const uint32_t *indices, uint32_t count,
    uint8_t *out_data, uint32_t capacity, uint32_t *out_required);
```

- 只读查询：不要求空闲，不改变 revision、文档与历史。
- `indices` 规则同上；输出为这些笔划按**索引升序**编码的**格式 1** 快照字节（魔数 `SCRATCH\0`，版本 1，无页面标识）。因此宿主可直接把它当剪贴板内容保存或跨页使用。
- 容量不足返回 `BUFFER_TOO_SMALL` 并把所需字节数写入 `out_required`，不写数据区；`capacity == 0` 与 `out_data == NULL` 组合仅用于查询所需大小（与 `sm_save` 相同）。
- `revision` 不匹配返回 `STALE_REVISION`；索引非法返回 `INVALID_ARGUMENT`。

## 粘贴

```c
SmStatus sm_paste(SmHandle handle, uint64_t revision,
    const uint8_t *data, uint32_t length, const SmTransform *transform);
```

- 只在空闲时可用；`revision` 不匹配返回 `STALE_REVISION`。
- 数据必须是**格式 1** 快照字节（即 `sm_copy_strokes` 的产物）；格式 2（`SCRATCH2`）返回 `INVALID_DATA`——粘贴不是恢复文档，跨页粘贴请用格式 1 的复制产物。魔数未知返回 `INVALID_DATA`，版本未知返回 `UNSUPPORTED_VERSION`，其余结构与样本校验沿用 M0 解码规则。
- 快照中笔划数为 0 是空操作：`OK`，不递增 revision、不产生历史条目。
- `transform` 可为 `NULL`（恒等）。变换后的坐标与线宽校验规则与 `sm_transform_strokes` 相同；失败返回 `INVALID_ARGUMENT` 且不改变文档。
- 粘贴把笔划追加到**笔划列表末尾**（位于所有既有笔划之上），内部顺序与快照顺序一致；一次调用只产生**一个**撤销条目（撤销整批消失，重做整批回来），并清除重做历史。
- 资源上限沿用“含历史在内最多 1,000,000 点、100,000 笔划”；超出返回 `LIMIT_EXCEEDED`，文档与历史保持原样。
- 不修改页面标识；快照格式不变（粘贴进来的笔划与手写笔划在快照里没有区别）。

## 验收边界

- 变换：平移 / 缩放 / 旋转 / 镜像 / 剪切各一组手算真值；线宽按 `√|det|` 缩放；时间戳、压力与 `flags` 不变；索引位置与 z 序不变；`count == 0` 空操作；非法矩阵（非有限、`det == 0`、`|det|` 越界）；越界坐标与线宽溢出导致整次失败且文档不变；活动笔划拒绝；stale revision；重复索引拒绝；单条撤销 / 重做。
- 复制：输出可按 M0 解码且笔划数与顺序与选区一致；空选区产出 0 笔的格式 1 快照；容量不足回报所需字节；查询模式；非法索引；stale revision；只读不改文档。
- 粘贴：复制 → 粘贴的往返；带变换粘贴（平移 / 旋转）；粘贴后在最上层且快照顺序保持；一次撤销整批消失、重做整批回来；格式 2 拒绝；截断数据 / 未知魔数 / 未知版本；空快照空操作；预算超限原子失败；活动笔划拒绝；跨文档粘贴（A 复制、B 粘贴）。
- 原 M0–M6 断言与共享夹具不改动，全部保持通过。
- 不实现剪贴板系统集成、选区变换的交互式手柄、形状规整、视口旋转、预测笔迹、多页管理、Android、MSVC / UWP；不声称实机拖拽手感或变换性能已达标。
