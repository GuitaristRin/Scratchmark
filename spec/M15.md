# M15 实验规格：预测的刷新率输入

状态：Canon，仅约束当前实验。SDK 0.15.0，ABI 1，快照格式仍为 1 / 2 / 3；M0–M14 的既有接口与行为保持不变，M10 的 `sm_predict` 与 `SmPredictionOptions` **逐位不变**。不承诺稳定发布兼容。

## 背景与能力位

原生侧的预测与刷新率挂钩：`外部实现::SetRefreshRate(float)`、`SetMaxPredictTime(float)`、`Predict(TouchPointSequence, Point)`
（`本地参考/本地参考/resources/lib/arm64-v8a/原生库`，证据见
`docs/research/2026-11-07-oppo-capability-inventory.md` 第六节）：

- **最大预测时间**：预测最多往前推多久；
- **刷新率**：一帧有多长，决定“这一帧只需要补多长”。

Scratchmark 的 M10 只有 `horizon_us`（等价于最大预测时间），没有刷新率输入。本规格补一个扩展选项与导出：
刷新率大于 0 时，**有效时间窗 = min(horizon_us, 1e6 / refresh_rate_hz)**；刷新率为 0 表示宿主未提供，行为与 M10 完全一致。

- `sm_features()` 新增 bit 13（`SM_FEATURE_PREDICT_REFRESH = 1<<13`）。

## 接口

```c
typedef struct SmPredictionOptionsEx {
    double horizon_us;      /* 最大预测时间，微秒 */
    double max_distance;    /* 预测尾迹最大长度，页面单位 */
    uint32_t count;         /* 1..64 */
    uint32_t reserved;      /* 必须为 0 */
    SmBrushOptions brush;   /* 与 M2 相同 */
    double refresh_rate_hz; /* 0 = 未提供；> 0 时参与有效时间窗 */
} SmPredictionOptionsEx;

SmStatus SM_CALL sm_predict_ex(SmHandle handle, uint64_t revision,
    const SmPredictionOptionsEx *options,
    SmBrushPoint *out_points, uint32_t capacity, uint32_t *out_written);
```

- 校验：`horizon_us`、`max_distance`、`count`、`reserved`、`brush` 沿用 M10；
  **新增** `refresh_rate_hz` 必须有限且落在 `[0, 10000]`（0 表示未提供）。
- 有效时间窗：`refresh_rate_hz == 0` 时等于 `horizon_us`；否则
  `frame_us = 1e6 / refresh_rate_hz`，`effective = min(horizon_us, frame_us)`，`effective` 必须是有限正数，否则 `INVALID_ARGUMENT`。
- 其余语义（速度合成、`max_distance` 收缩、页面域截断、笔宽取最后一个笔刷点、无活动笔划时零预测点、容量语义）
  与 M10 **完全一致**，只是把 `horizon_us` 换成 `effective`。
- `sm_predict` 与 `SmPredictionOptions` 保持原样：老宿主的行为与 M10 逐位相同。

## 验收边界

- `refresh_rate_hz = 0`：与 `sm_predict` 同参数的结果**逐点相同**。
- `refresh_rate_hz = 240`、`horizon_us = 16000`：有效窗 ≈ 4166.67 微秒，预测长度短于不提供刷新率的情形。
- `refresh_rate_hz = 10000` 与极大 `horizon_us`：有效窗由刷新率决定。
- 非法：负 / 非有限 / 超 10000 的刷新率、`effective` 非正、以及 M10 的全部非法组合；一律不写输出。
- 原 M0–M14 断言与共享夹具不改动，全部保持通过。
- 不实现帧同步、渲染节拍回调、按帧丢弃策略；不声称实机延迟改善。

## 范围与边界

刷新率只是**预测窗的上限来源**，不是时钟：引擎不排帧、不回调、不读设备。宿主自己决定何时问、何时丢。
