# M6 实验规格：套索命中、批量删除与清空

状态：Canon，仅约束当前实验。SDK 0.1.0，ABI 1，快照格式仍为 1 / 2；M0 / M2 / M3 / M4 / M5 的既有接口与行为保持不变（参 `M0.md`、`M2.md`、`M3.md`、`M4.md`、`M5.md`）。不承诺稳定发布兼容。

## 能力位

- `sm_features()` 新增 bit 4（`SM_FEATURE_SELECTION = 1<<4`）。
- 引擎不保存“选区”状态：命中查询是只读纯计算，选区与高亮由宿主保留；批量删除按调用时给出的索引执行。

## 套索命中

```c
SmStatus sm_lasso_hits(SmHandle handle, uint64_t revision,
    const SmPoint *path, uint32_t count,
    uint32_t *out_indices, uint32_t capacity, uint32_t *out_written);
```

- `path` 是页面坐标下的**闭合多边形**顶点序列：按传入顺序连接，末点自动连回首点。`count >= 3`；`count` 上限沿用 M0 批大小 65,536；越界返回 `LIMIT_EXCEEDED`，`count < 3` 返回 `INVALID_ARGUMENT`。
- 每个顶点必须有限且绝对值不超过 1e9，否则 `INVALID_ARGUMENT`。
- 内部判定用**穿越计数（even-odd）**：自交路径可能把某个环判为外部，宿主不应把自交手势当合法选区。
- 一个已提交笔划“被选中”当且仅当它的**原始中心线**与多边形区域有交集：
  - 任一中心线顶点严格位于多边形内部；或
  - 任一中心线段与任一多边形边相交（含端点接触、共线重叠）。
  - 单点笔划只按内部判定。
- 只查已提交笔划，活动笔划不参与；`M2` 派生轨迹不参与判定。
- 输出为命中笔划索引，**升序**（等于 z 序），写入宿主缓冲区。
- 容量不足时返回 `BUFFER_TOO_SMALL` 并把所需数量写入 `out_written`，不写数组；`capacity == 0` 与 `out_indices == NULL` 组合仅用于查询数量。命中数为 0 时返回 `OK`，`out_written` 写 0。
- 查询本身不要求空闲、不改变 revision / 文档 / 历史；`revision` 不匹配返回 `STALE_REVISION`。
- 检查顺序：缓冲区指针 / `count` 上限（M0 规则）→ `revision` → 路径点与 `count < 3`（`INVALID_ARGUMENT`）→ 容量（`BUFFER_TOO_SMALL`）。

## 批量删除

```c
SmStatus sm_erase_indices(SmHandle handle, uint64_t revision,
    const uint32_t *indices, uint32_t count);
```

- 只在空闲时可用；有活动笔划返回 `INVALID_STATE`。`revision` 不匹配返回 `STALE_REVISION`。
- `count == 0` 是空操作：返回 `OK`，不递增 revision、不产生历史条目。
- 每个索引必须 `< stroke_count`，且**不得重复**（重复索引返回 `INVALID_ARGUMENT`，不猜测宿主意图）。顺序任意，引擎自行排序。
- 成功时一次调用只产生**一个**撤销条目：删除这些笔划，递增 revision，清除重做历史。撤销按原索引逆序插回，z 序与顺序完全恢复；重做再次删除。
- 删除不改变“含历史在内”的点数 / 笔划预算：被删笔划由撤销历史持有，直到重做历史被清除才释放。
- 快照仍只保存存活笔划；载入后重做历史清空。
- 不修改页面标识；页面标识规则沿用 M3。

## 清空

```c
SmStatus sm_clear(SmHandle handle, uint64_t revision);
```

- 只在空闲时可用；`revision` 不匹配返回 `STALE_REVISION`。
- 已无已提交笔划时是空操作：`OK`，revision 不变、不产生历史条目。
- 否则删除全部已提交笔划，作为**一个**撤销条目；撤销恢复全部笔划与原 z 序；一次撤销即回到清空前。
- 不改页面标识、不改快照格式。

## 验收边界

- 套索：空文档、三顶点最小多边形、完全内含、部分相交、只接触边界、完全在外、单点笔划、活动笔划排除、自交路径、凹多边形、重复顶点、容量不足与查询模式、非法路径、`count < 3`、超上限、stale revision、无输出写入。
- 删除：索引越界、重复索引、空列表、活动笔划拒绝、stale revision、撤销恢复原 z 序、重做再删、`clear` 单条撤销、`clear` 空文档不改 revision、快照往返、load 后重做清空。
- 原 M0 / M2 / M3 / M4 / M5 断言与共享夹具不改动，全部保持通过。
- 不实现选区变换（移动 / 缩放 / 旋转）、形状规整、预测笔迹、多页管理、Android、MSVC / UWP；不声称实机套索手感或选择性能已达标。
