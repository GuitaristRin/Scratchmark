# M2 实验规格：平滑与压力派生几何

状态：Canon，仅约束当前实验。SDK 0.2.0，ABI 1，快照格式仍为 1。原接口与固定宽度原始几何行为保持，参 `M0.md`；不承诺稳定发布兼容。

## 配置与算法

- `SmBrushOptions`：f64 alpha、f64 min_width_ratio、u32 pressure_enabled、u32 reserved，自然对齐，大小 24。alpha 和 ratio 必须有限且在 (0,1]；pressure_enabled 为 0/1，reserved 必须 0。
- `SmBrushPoint`：f64 x、y、width，自然对齐，大小 24；width 是页面坐标中的完整笔宽，不是半径。颜色取原笔划元数据。
- 每个原始样本对应一个派生点。第一点坐标等于原始第一点；后续坐标逐轴为 `previous + alpha * (raw - previous)`。alpha=1 时逐点原样输出；不使用未来点、不额外等待、不在 finish 时暗改笔尾。
- 启用压力且该样本 flags=1 时，`width = stroke.width * (min_width_ratio + (1-min_width_ratio)*pressure)`；若下溢到 0 则取最小正 subnormal。未启用或缺少真实压力时，width=stroke.width。笔宽本轮不另做时间滤波，不把速度伪装成真实压力。
- 平滑是按样本而非按时间加权的实验低通；输入频率、alpha 与轨迹滞后相关，拐角 / 笔尾可能滞后。无自动“最佳参数”或实机手感承诺。width 始终为正且不超过原笔宽，派生轨迹落在原样本的保守边界内。
- 几何表示为中心线与逐点线宽；宿主可按相邻点的线性半径插值扫掠圆盘呈现，单点为圆盘。引擎不拥有 UI 或光栅化后端。

## 读取、状态与缓存

- `sm_features()` 返回 u64 能力位，bit 0 表示本规格的派生笔刷读取。其他位宿主忽略。新 C# 绑定在创建文档前核对 ABI 1 及此能力，不把缺导出留到实际书写时才暴露。
- `sm_read_brush_points(handle, revision, index, start, options, out_points, capacity, out_written)` 沿用原 revision、索引、分段和容量规则。活动笔划可读；首尾、点数及 start 均对应原始样本索引。
- 配置和标量指针必须有效、对齐；数据区容量为 0 可为 NULL。状态码、容量限制、错误不写输出、内存所有权沿用 M0。缓存变化不改 revision 或历史。
- 每笔最多保留一组读取配置的派生缓存。相同配置分段读取复用前缀；后续 append 只扩展已缓存轨迹。切换配置重算，旧缓存释放。缓存不保存到快照，也不引用宿主内存。
- 原始 read_points、元数据的最大固定笔宽、撤销 / 重做和快照字节均保持。原始样本的原子验证先于任何缓存更新；失败不能改变缓存对应的轨迹。

## 持久化与范围

格式 1 保存原始坐标、时间、压力及原笔宽；读取时传相同配置即可恢复相同派生结果。alpha、压力开关和最小笔宽比例由宿主保存 / 选择，本轮未实现每笔专属笔刷样式的持久化。不得声称单独一份快照保存了这些显示配置。

验收使用手算真值、原共享夹具、独立宿主和由真实 DLL 输出生成的离线图；不修改原夹具和既有测试。Android、设备手感、预测、拐角自适应、压力曲线调校与硬件延迟不在本轮结论内。
