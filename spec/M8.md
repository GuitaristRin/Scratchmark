# M8 实验规格：形状规整

状态：Canon，仅约束当前实验。SDK 0.8.0，ABI 1，快照格式仍为 1 / 2；M0–M7 的既有接口与行为保持不变（参 `M0.md`…`M7.md`）。不承诺稳定发布兼容。

## 能力位

- `sm_features()` 新增 bit 6（`SM_FEATURE_SHAPE = 1<<6`）。

## 形状种类

```c
enum {
    SM_SHAPE_LINE = 1, SM_SHAPE_RECTANGLE = 2, SM_SHAPE_CIRCLE = 3, SM_SHAPE_ARROW = 4
};
```

宿主显式指定种类，引擎**不做自动分类**：把“这一笔是不是想画矩形”留给宿主策略，避免引擎里出现无法证伪的启发式。

## 接口

```c
typedef struct SmShapeInfo {
    uint32_t kind;         /* 实际生成的形状种类（等于请求的种类） */
    uint32_t stroke_count; /* 生成几笔：直线 / 矩形 / 圆为 1，箭头为 3 */
    uint32_t point_count;  /* 生成的总点数 */
    uint32_t reserved;     /* 必须为 0 */
    double error;          /* 原始中心线到生成几何的 RMS 距离（页面单位） */
} SmShapeInfo;

SmStatus sm_regularize_stroke(SmHandle handle, uint64_t revision,
    uint32_t index, uint32_t kind, uint32_t flags, SmShapeInfo *out_info);
```

- `flags` 只允许 bit 0：置位表示**只测量不替换**（预览）。其余位非零返回 `INVALID_ARGUMENT`。
- 预览是只读：不要求空闲、不递增 revision、不写历史、不改文档；仅校验 `revision`、`index`、`kind`、`flags`。
- 非预览（实际替换）要求空闲（有活动笔划返回 `INVALID_STATE`），成功时把索引 `index` 处的笔划替换为 1–3 笔，递增 revision，清除重做历史，并只产生**一个**撤销条目。
- `index` 必须指向已提交笔划，否则 `INVALID_ARGUMENT`；`revision` 不匹配返回 `STALE_REVISION`；未知 `kind` 返回 `INVALID_ARGUMENT`。
- `out_info` 指针必须有效且对齐，失败时不写入。

## 几何与生成规则

生成的笔划**继承原笔划的颜色与线宽**（规整不改变粗细）；样本 `flags = 0`、`pressure = 0`；样本时间在原始首末时间之间按点数线性分布（首点取原首时间，末点取原末时间）。坐标系为页面坐标，与 M0 的页面域一致：生成点必须有限且绝对值不超过 1e9。

- **直线**（`LINE`）：对原始点做总体最小二乘（先减去质心，再取协方差主方向的 `θ = ½·atan2(2Sxy, Sxx−Syy)`），端点取原始点在主方向上投影的最小 / 最大处。生成 2 点。要求原始点数 ≥ 2 且投影长度 > 0，否则 `INVALID_ARGUMENT`。
- **矩形**（`RECTANGLE`）：取原始点的轴对齐包围盒，生成 5 点闭合回路（四角 + 回到首角，保持传入顺序）。要求宽与高都 > 0，否则 `INVALID_ARGUMENT`。
- **圆**（`CIRCLE`）：Kåsa 圆拟合（同样先减去质心以保证数值稳定），用 Cramer 法则解 3×3 正规方程；圆心与半径必须有限、半径 > 0 且圆上所有点落在页面域内，否则 `INVALID_ARGUMENT`。生成 65 点（64 段闭合回路，末点等于首点）。
- **箭头**（`ARROW`）：先按直线规则拟合轴，箭杆为 [起点, 终点]，箭头长度 = 0.18 × 杆长，半角 28°，在终点处生成两条箭头边。生成 3 笔（箭杆 + 左右箭头边），共 6 点。要求与直线相同的退化判据。
- `error` 是该种类几何的拟合残差：
  - 直线 / 箭头：原始点到**轴线**的 RMS 距离；
  - 矩形：原始点到**矩形轮廓**（四条边的最短距离）的 RMS；
  - 圆：`RMS(|‖p − c‖ − r|)`。
  残差用于宿主判断是否采纳（例如超过阈值就保留手写），引擎不设“像不像”的阈值。

## 资源与历史

- 资源上限沿用“含历史在内最多 1,000,000 点、100,000 笔划”。规整可能让点数变多（圆固定 65 点、箭头 6 点 3 笔），替换前检查：`retained + 生成点数` 与 `retained + 生成笔划数` 超限时返回 `LIMIT_EXCEEDED`，文档与历史保持原样。
- 一次实际替换只占一个撤销条目：撤销恢复原始手写笔划与原索引、原 z 序；重做再次规整。
- 生成笔划占据原索引（箭头为连续的 3 笔，从原索引开始），其他笔划相对顺序不变。
- 不修改页面标识；快照格式不变（规整结果是普通笔划）。

## 验收边界

- 直线：水平 / 垂直 / 斜线 / 含噪声的手写线，端点方向、误差、生成点数；单点与全等点被拒绝。
- 矩形：轴对齐包围盒、闭合回路点数、宽或高为 0 被拒绝、误差。
- 圆：整圆、带噪声的圆，圆心 / 半径 accuracy，65 点闭合，退化（共线点）被拒绝、越界被拒绝。
- 箭头：3 笔 6 点、箭头边方向与长度、误差按轴线计算、退化被拒绝。
- 通用：颜色与线宽继承、`flags/pressure` 归零、时间线性且非递减、索引与 z 序、一次撤销 / 重做、预览不改变任何状态、未知 kind、非法 flags、活动笔划、stale revision、索引越界、预算超限原子失败、快照往返。
- 原 M0–M7 断言与共享夹具不改动，全部保持通过。
- 不实现自动形状分类、吸附预览、手柄编辑、文字识别、平滑参数联动；不声称实机识别率或手感已达标。
